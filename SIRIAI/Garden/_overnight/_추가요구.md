# LUN8 대시보드 야간작업 — 추가 요구 (2026-07-16, 사용자 취침 전 브리프)

야간 이어작업(초안 대시보드 완성) + 아침 검토가 참고할 브리프. 기존 워크플로우 산출물과 함께 볼 것.

## 새로 추가된 관점 (필수 반영)
1. **소규모 팀 유연성 (나 포함 4명)** — 팀원이 "이것도 추가하고 저것도 수정하고" 유연하게 할 수 있어야 함.
   - 새 캠페인 = config 교체 / 새 열 = 헤더기반 자동인식 / 인원 추가 = 대시보드에서 / 시트 편집(색·열)에 관용적
   - **개발자 없이도** 흔한 변경이 되게. 설정/추가가 쉬운 UI 또는 config.
2. **기본 원칙 = "쉬워야 한다".** 절대 잊지 말 것. 복잡하면 실패. 뺄 수 있으면 뺀다(절제).
3. **폴더 재구성** — 폴더명이 `garden`인데 범위가 (가드닝 → **멀티캠페인 대시보드 시스템**)으로 확장됨.
   - ⚠️ **실제 rename은 야간에 실행 금지.** 라이브 Vercel(root dir)·git 서브트리·campaigns.json·.claude/launch.json 경로·스크래치패드를 깨뜨림.
   - 대신 **"재구성 제안 문서"만** 작성(`_overnight/03_폴더재구성_제안.md`): 새 이름 후보·새 구조(트리)·바꿔야 할 것 목록(Vercel 설정·경로 등). 아침에 사용자와 함께 안전하게 실행.
