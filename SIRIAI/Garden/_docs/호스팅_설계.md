# 팀 편집 가능한 호스팅 버전 — 설계도

## 핵심 한 줄
**틱톡 "스캔"만 로컬이어야 하고, 나머지(보기·편집·집행)는 전부 클라우드로 옮길 수 있다.**
마스터시트는 이미 공유(브릿지=공개 주소), smmkings도 공개 API. 지금 로컬 파일에만 있는 주문·검수기록만 시트로 옮기면 됨.

## 뭐가 바뀌나

| 구성요소 | 지금(로컬) | 목표(호스팅) |
|---|---|---|
| 대시보드 UI | 로컬 서버가 서빙 | **Vercel 호스팅** (팀이 URL로 접속) |
| 백엔드(주문·집행·환율) | `src/server.js` (내 PC) | **Vercel 서버리스 함수** |
| 상태 저장 | 로컬 `data/*.json` | **마스터시트로 이전** (주문·검수잠금·베스트) |
| 틱톡 스캔 | 대시보드 버튼 | **로컬 스캔 워커**(scan.bat) — 유일한 로컬 |
| smmkings 키 | 로컬 .env | Vercel 환경변수(서버측, 노출 안 됨) |

## 정직하게 — 진짜 어려운 것 2개

1. **로컬 상태 → 시트 이전** (핵심 난관)
   지금 `data/`에 있는 것: 주문/집행내역·비용, 검수 수동잠금(overrides), SIRIAI 베스트. 이걸 마스터시트의 숨은 탭/열로 옮기고, 브릿지(Code.gs)가 읽고 쓰게 확장해야 함. 옮기는 동안 돈 로직(중복주문 방지 등) 재검증 필수.

2. **여러 명 동시 사용 = 새로운 위험**
   지금은 너 혼자라 없던 문제인데, 팀이 동시에 쓰면:
   - 두 명이 같은 계정 **집행 동시 클릭 → 이중지출**. → 집행에 락(잠금) 필요.
   - 동시 편집 충돌. → 시트가 마지막 저장 우선이라 대체로 괜찮지만 집행만 신중.

## 집행(돈) 권한
호스팅되면 아무나 "집행" 누르면 실제 돈이 나감. 그래서:
- smmkings 키는 서버측(Vercel)에만 — 노출 안 됨.
- **집행 버튼에 비번/권한 게이트** — 지정된 사람만 돈 쓰게. (보기·편집은 열어두고 집행만 잠금)

## 단계 (현재 안 깨지게 순서대로)

1. **상태 이전** — 브릿지 확장(주문·검수잠금·베스트 시트에), 로컬 앱을 "시트=유일한 상태"로 전환·검증
2. **스캔 분리** — 스캔 로직을 독립 `scan.bat`으로, 결과는 시트에 기록. 웹앱은 "마지막 스캔 시각"만 표시
3. **Vercel 전환** — server.js 엔드포인트 → 서버리스 함수(스캔 제외), 프론트는 거의 그대로
4. **권한·동시성** — 집행 비번 게이트 + 동시 집행 이중지출 락
5. **배포·팀 테스트**

## 난이도 / 기간 감
- **이 프로젝트 최대 규모.** 여러 세션 걸림.
- 1단계(상태 이전)와 4단계(동시성/돈)가 신중해야 할 구간.
- 나머지(2·3·5)는 비교적 기계적.

## 네(사용자)가 할 것
- **Vercel 계정 연결** (무료 플랜으로 가능) — 1회
- **브릿지 재배포** 1회 (새 상태 탭 추가분)
- **팀 접속 비번 + 집행 비번** 정하기
