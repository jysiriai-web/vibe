# 3_send — 자동 발송 (사이클 3단계) 🔨 설계 완료·구현 대기

> 상세 설계는 **[PRD.md](PRD.md)**. 이 파일은 요약.

## 1. 목적
`2_compose`가 작성하고 **사람이 승인(발송단계=승인)한 메일만** Gmail로 전송. 가장 되돌릴 수 없는 단계 → 3겹 안전선.

## 2. 3겹 안전선
1. **적합도 필터** — `발송적합도=적합`만 진입(부적합/민감은 _보류에 격리, 1_collector가 이미 분리).
2. **법적 가드(`compliance.py`)** — 정보통신망법: 야간 21~08시 금지·발신자 표기·무료 수신거부·(광고) 토글. 위반 시 전송 차단.
3. **사람 승인 게이트** — 자동 승인 절대 없음. 하루 1회 검토→`--send`.

## 3. 도달성 현실 (2026 기준, ★기존 50~80통 폐기)
- 콜드메일 안전 발송량 = **하루 15~25통/계정**(2025말 단속 후). 신규 계정은 12통부터 워밍업.
- 발송 간격 45~120초 랜덤. 스팸률 0.1% 미만 유지(초과 시 자동 일시정지).
- **@gmail.com 개인계정은 한계** → 진지하게 돌리려면 커스텀 도메인+Workspace+SPF/DKIM/DMARC 권장.
- 179 적합 ≈ 9~12 발송일(워밍업 포함 ~2주).

## 4. 구조
```
3_send/
├── run.py        진입점 (--preview / --send [--yes])  ✅스켈레톤

├── suppress.py   수신거부/바운스 명단(_수신거부)        ✅동작
├── gmail.py      Gmail API OAuth·전송                  ✅스켈레톤(OAuth 셋업 필요)

└── README.md
```
- 인증: Gmail OAuth(`gmail.send`, jysiriai@gmail.com) — 시트용 서비스계정과 **별개**. 토큰 `secrets/gmail_token.json`(gitignore).
- 의존 패키지 추가 필요: `google-api-python-client`, `google-auth-oauthlib`.

## 5. 인터페이스 (시트로만 연결, 코드 의존 0)
