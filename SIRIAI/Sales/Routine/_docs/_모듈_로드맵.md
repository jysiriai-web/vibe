# SIRIAI 영업 자동화 — 모듈 로드맵 (전체 설계)

> 전체 프로세스를 **10개 모듈**로. 메인 순서 0→7 + 사이드 2개(8 후속·9 현황판).
> 갱신: 2026-06-13 (번호 정리 + 회신/무회신 두 흐름 반영)

## 전체 흐름 (회신 온다 / 안 온다 두 갈래)
```
0 소싱 → 1 검증·이메일 → 2 작성 → 3 발송 → 4 추적 ─┬─ 회신 옴   → 5 회신·답장 → 6 제안대시보드 ─┐
                                                    │                  └────[5답장+6대시보드 합쳐 회신]────┤
                                                    │                                                      ▼
                                                    │                                                  7 미팅·계약 → 성사
                                                    └─ 회신 없음 → 8 후속(N일 뒤 리마인드 1회) → 다시 4 추적

       [옆에서 계속 도는 것]   8 후속·리마인더(정체된 건 챙김)   ·   9 현황판(전체 퍼널 집계)
```

## 모듈 10개 (번호순)

| # | 모듈 | 목적 | 입력 → 출력 | 상태 |
|---|---|---|---|---|
| 0 | **intake** | 브랜드 소싱·전달 (수기 입력, 추후 자동 소싱) | (외부) → 6월 신규 행 | ⬜ 설계 |
| 1 | **collect** | 회사명→브랜드 검증·이메일·적합도·안전장치 | 신규 행 → 발송적합도·메일주의·이메일 | ✅ 가동 |
| 2 | **compose** | 적합 브랜드 개인화 초안 작성 | 적합 → 발송단계=초안+훅 | ✅ 완료 |
| 3 | **send** | 승인분만 발송(3겹 안전선·정보통신망법) | 승인 → 발송+발송일자 | 🔨 OAuth 대기 |
| 4 | **track** | 열람·클릭·회신 감지 → 시트 동기화 | 발송 → 열람·클릭·회신/회신일자, 발송단계=회신 | ⬜ 설계 |
| 5 | **reply** | 회신 분류(관심/거절/문의) + 답장 초안 | 회신 → 분류·답장초안, 관심=리드 | ⬜ 설계 |
| 6 | **proposal** | 관심 브랜드 맞춤 제안 대시보드 (5와 짝: 답장+대시보드 합쳐 회신) | 리드 → 제안 페이지 | ⬜ 설계 |
| 7 | **deal** | 미팅 일정·계약 성사 관리 | 미팅 → 계약·성사여부 | ⬜ 설계 |
| 8 | **follow-up** | (사이드) 회신 없으면 N일 뒤 리마인드 1회·정체 건 챙김 | 발송일자·회신일자 → 후속 대상 | ⬜ 설계 |
| 9 | **report** | 운영 현황 대시보드(전체 퍼널 집계) | 6월 전체 → 퍼널 KPI | ⬜ 설계 |

> 메인 순서 = **0~7 순차** (0소싱→…→5회신·답장→6제안→7미팅·계약). **8 후속·9 현황판은 순서 단계가 아니라 옆에서 도는 것.**

## 공통 원칙 (전 모듈)
1. **시트 = 상태머신.** 모듈끼리 코드 의존 0, 오직 6월 탭의 열(발송단계 등)로 연결. 멱등.
2. **안전:** 모든 쓰기 = 백업 → dry-run → apply. 되돌릴 수 없는 단계(발송)는 사람 승인 게이트.
3. **이중처리 방지:** 이미 처리된 상태는 재처리 안 함(누적식).
4. **안전장치 동행:** `메일주의`(민감 제품군 경고)가 발송·회신까지 따라감.

## 상태머신 (`발송단계` 열 — 6월 탭)
```
초안 → 승인 → 발송 → [열람·클릭] → 회신 ─┬─ 관심 → 리드 → 미팅 → 계약 → 성사
                                          ├─ 거절 → 종료
                                          ├─ 무응답 → (8 후속 N일 뒤 1회) → 종료
                                          └─ 수신거부 → 제외(영구)
보류 = 발송 대상 아님(_보류 탭)
```
