# 인터참 사후 팔로업 메일 — 설계 문서 (v0 · 팀 공유용)

> **상태: 설계단계.** "어떤 일을, 얼마나" 를 확정하는 단계. **카피·초안·HTML은 아직 안 씀.**
> 목적 = **레퍼런스를 충분히 깔고 "좋은" 템플릿을 뽑기.** 그래서 레퍼런스 수집·분석이 앞단 토대 작업.
> 작성 2026-07-14. 상위 규칙: [`../../메일_PRD.md`](../../메일_PRD.md) · 브랜드토큰(siriai-brand-design-tokens).
> 배경: 인터참(7/1~3 COEX) 현장 명함/접점 브랜드 대상. 오늘 기준 **박람회 종료 11일 경과** → 사전 인사가 아니라 **사후(事後) 팔로업**.

---

## 1. 목표 (한 줄)
현장에서 접점 생긴 인터참 참가 브랜드에게 **기억이 남아있을 때 가볍게 다시 연결** → 다음 대화(회신·미팅)로. 단, 급조가 아니라 **레퍼런스 기반의 잘 만든 템플릿**으로.

## 2. 이번에 확정한 방향

| 항목 | 결정 |
|---|---|
| **템플릿 수** | **2종, 발송 대상별** 분기 (관심도별 아님) |
| **A. 담당자 버전** | 명함에 **이름·직급 有** → 실명·직급 + "인터참에서 뵌" 맥락. 웜. |
| **B. 브랜드 공식 버전** | 이름 없이 **브랜드 대표메일** → 브랜드의 인터참 참가를 웜하게. 개인 지칭 X. |
| **합칠 때** | 두 본문이 결국 같아지면 → **담당자 버전 하나로 발송.** |
| **톤** | **웜**(콜드보다 완화). 명함 교환·현장 접점이 사실이므로. 단 브랜드명·법 안전요건은 유지. |
| **(광고) 표기** | **안 함.** 랜덤 발송 아니고 명함 교환(주기로 하고 받음) 기반. [준용 결정] |
| **구조 원칙** | **1 코어 + 2 서론.** 인사·개인화(서론)만 A/B로 갈리고 본론은 공유. |

## 3. 작업 설계 — 어떤 일을, 얼마나

### 지금 · 설계단계 (토대를 깐다) — 합 ≈ 4~6.5시간

**① 레퍼런스 수집·분석 [핵심 토대] — 3~5시간**
- 기존 자산 선별 — [`../../references_email_design.md`](../../references_email_design.md) 103종에서 이 케이스(사후·웜·뷰티 B2B·국문)에 맞는 것 추림
- 신규 타겟 수집 — 트레이드쇼/전시 후속, "다시 연결(reconnect)" 메일, 뷰티 브랜드↔에이전시 아웃리치, 국내 B2B 실사례
- 실물 뜯어보기 — 잘 된 사후 팔로업 메일의 구조·제목·CTA·길이·비주얼 분해
- 합성 → 설계 원칙 (제목/프리헤더/훅/CTA/길이/비주얼 수위)
- **산출물 = 레퍼런스팩** (링크 + 왜 좋은지 + 우리 적용점)

**② 설계 스펙·결정 정리 [토대] — 1~1.5시간**
- 레퍼런스 원칙 × 우리 제약(PRD·브랜드토큰·법·기술) 교차 → 설계 스펙
- A/B 2종 분기 스펙 확정
- 열린 결정 목록화(아래 §5)
- **산출물 = 설계 스펙 1장** (팀 정렬용)

### 다음 · 팀 정렬 후 (스펙대로 만든다) — 합 ≈ 5~6.5시간
- **카피 작성 ≈ 2h** — 제목 세트·프리헤더·본문·훅·CTA (레퍼런스·스펙 기반, **지금 아님**)
- **HTML 제작 2~3h** — 브랜드토큰 시안 + 법·기술 마감(테이블·불릿프루프·프리헤더·다크모드·plain 멀티파트)
- **렌더 QA·정리 1~1.5h** — Gmail·모바일·다크모드 실측 · 슬롯 계약 · 폴더 정리

### 별도 트랙 (병렬) — 분량 미정
- **명함 데이터 준비** — 디지털화·시트 입력·훅 채우기. 템플릿과 무관하게 **발송의 실제 병목** (현재 미완).

> **정리:** 지금(설계) 반나절~하루 + 정렬 후 제작 반나절~하루 = 집중 **1~2일**. 질은 앞단 레퍼런스 토대에서 나오므로 거기 시간을 쓴다. 발송은 명함 데이터가 별도로 굴러야 가능.

## 4. 메일 블록 순서 (역할만 · 카피는 설계 후)

받는 사람이 위→아래로 보는 순서. ②만 A/B로 갈리고 ③은 문구만, ④~⑨는 공유.

```
① 발신 정체        누가 보내는가
② 개인화 인사      ★A/B 분기 (A: 실명·직급 / B: 브랜드·인터참 참가)
③ 인터참 맥락      과거시제 한 줄 (11일 경과 반영) · A/B 문구만 다름
④ 우리 소개        뭐 하는 곳인지 짧게
⑤ 떡밥·가치        핵심 차별점(맞춤 선별) — 메일의 알맹이
⑥ 포함 자산        ★열린 결정 (아래 §5-1)
⑦ CTA             소프트 질문형 (직접 미팅 요구보다 답장률↑)
⑧ 서명            발신자·연락처
⑨ 수신거부 한 줄   법 최소 안전장치
```

## 5. 열린 결정 (팀과 함께 · 설계 스펙에서 확정)

1. **포함 자산 범위** — ⚠️ PRD §4는 **링크 1~2개** 권장(과다 = 스팸 리스크). 포트폴리오+사업소개서+홈페이지 다 넣으면 3+ → 충돌. 우선순위/개수 정해야.
2. **"첫 오픈 경험"** — 뭘 쉽게 줄까? (원칙 후보: 1분 스캔 + 명확한 다음 스텝 하나)
3. **랜딩페이지 — 쓸지 말지부터.** (기존 인터참 랜딩은 사전 카피. 안 쓰고 메일→자산 직결도 선택지)
4. **제목·프리헤더 방향** (레퍼런스팩 기반)
5. **비주얼 수위** — 텍스트 우세 vs 브랜드토큰 리치.
6. **길이** — 짧은 리마인더형 vs 소개 겸한 중간형.
