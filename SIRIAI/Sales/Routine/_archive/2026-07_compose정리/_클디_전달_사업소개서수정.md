# 클로드 디자인 전달용 — 사업소개서 딥링크·문항 수정 요청

> 인터참 사후 팔로업 이메일(193곳 발송 예정)이 이 사업소개서로 사람을 보냅니다.
> 아래는 **이메일 쪽에서 확정된 사항**과, 그에 맞추기 위해 사업소개서에서 필요한 작업입니다.
> 작성 2026-07-19 · 실측 대상 `https://siriai-qa-deck.vercel.app/`

## 그대로 복사해서 쓰실 프롬프트

```
SIRIAI 사업소개서(siriai-qa-deck)에 딥링크를 붙이려고 합니다.
인터참에서 명함을 교환한 193개 브랜드에 이메일을 보내고, 그 메일의 링크가 이 페이지로 옵니다.

■ 지금 상태 (실측)
- 페이지의 id는 dc-root / dcroot / scrollSpacer / mailDraft 넷뿐입니다.
- #different, #how, #cost 로 접속해도 scrollY가 0에서 움직이지 않습니다. 딥링크가 없는 상태입니다.
- 첫 화면에 노출되는 질문: "어떤 서비스가 있나요?", "시리아이만의 강점이 있나요?",
  "어떻게 진행되나요?", "북미 마케팅은 어떻게 하나요?", "중국 마케팅은 어떻게 하나요?",
  "다른 나라들도 진행하나요?", "연예인·셀럽도 섭외할 수 있나요?",
  "인스타그램 매거진도 가능한가요?", "댄스 챌린지도 되나요?"
- 비용에 대한 질문·답변이 없습니다.

■ 요청 1 — 딥링크를 "점프"가 아니라 "바로 그 화면"으로
가장 중요합니다. 이전 방식(메인 화면이 잠깐 보였다가 해당 질문으로 스크롤 이동)은
사용해보니 경험이 나빠서 쓰지 않기로 했습니다. 화면이 한 번 튀는 게 고장처럼 보입니다.

원하는 동작:
- 특정 URL로 들어오면 **처음 그려질 때부터** 해당 답변 화면이 떠 있어야 합니다.
- 메인 화면이 한 프레임도 보이면 안 되고, 스크롤 애니메이션도 없어야 합니다.
- 즉 mount 이후에 scrollIntoView 하는 방식이 아니라,
  location을 읽어 **초기 상태값 자체를 그 답변으로 설정**하는 방식으로 해주세요.
- 뒤로가기를 누르면 메인으로 정상 복귀해야 합니다.
- 딥링크로 들어와도 다른 질문으로 이동할 수 있어야 합니다(막다른 화면 금지).

■ 요청 2 — 이메일이 걸 링크 3개
이메일 Q&A 영역에서 아래 세 개를 링크합니다. URL 형식은 정해주시는 대로 맞추겠습니다.
(해시 #, 쿼리 ?q=, 경로 /q/... 무엇이든 상관없습니다. 위 "바로 그 화면" 조건만 지켜지면 됩니다.)

  1) SIRIAI는 어떤 곳인가요?   → 메인 (지금처럼 첫 화면)
  2) 어떤 서비스가 있나요?     → 해당 답변 화면
  3) 비용은 얼마나 드나요?     → 해당 답변 화면

■ 요청 3 — 비용 문항 신설
현재 사업소개서에 비용 관련 문항이 없습니다.
이메일에서 "비용은 얼마나 드나요?"로 보내는데 답이 없으면 약속 위반이 됩니다.
문항을 만들어 주세요. 단, **단가는 노출하지 않습니다.**
"목표 규모를 먼저 듣고 거기에 인원과 범위를 맞춘다"는 구조 설명까지만 하고,
구체적 금액은 상담으로 넘기는 형태로 부탁드립니다.

■ 요청 4 — 오타
첫 화면 캠페인 영역에 "튍결 CAMPAIGN" 이라고 표기돼 있습니다. "틈결"의 오타로 보입니다.

■ 요청 5 — 이메일에서 오는 사람의 맥락
이 사람들은 광고를 보고 온 게 아니라 **2주 전 박람회에서 명함을 주고받은 사람들**입니다.
"처음 오신 분"을 전제로 한 안내보다, 이미 한 번 만난 사이라는 톤이 맞습니다.
```

## 참고 — 이메일 쪽에서 이미 확정된 것 (클디가 알면 좋은 맥락)

**메일 구조 (7블록)**
히어로 → 인사 → 훅 → **프로모션 리스트 + 전용코드 + CTA** → 강점 3 → Q&A → 아웃트로

혜택(리스트)이 강점·Q&A보다 **먼저** 옵니다. "하고 싶은 게 뭔지 안 와닿는다"는 피드백을 반영한 순서입니다.

**메일이 하는 약속** — 이 문장들이 참이어야 사업소개서 쪽도 어긋나지 않습니다.
- `{{brand}}에 맞춰 추린 인플루언서 100명`
- `확인하시기 편하게 대시보드로 만들어 두었습니다`
- `리스트는 내려받아 직접 쓰셔도 됩니다`
- CTA `프로모션 리스트 받아보기 →` → `siriai-qa-deck.vercel.app/?code={{전용코드}}`

**`?code=` 처리** — 브랜드별 전용 코드 193개가 시트에 생성돼 있습니다(예: `MOODCOLOR`).
CTA가 이 파라미터를 달고 오면 **코드 입력 없이 바로 해당 브랜드 대시보드**가 열려야 합니다.
코드 없이 들어온 경우에만 입력 화면을 보여주는 구조입니다.

**톤앤무드** — 메일은 검정 지면 + Inter Tight로 홈페이지(cd-study-deploy.vercel.app)와 맞춰져 있는데,
사업소개서는 크림 지면(#F3EEE2) + Pretendard라 링크를 누르는 순간 색이 확 바뀝니다.
셋 중 어디를 기준으로 통일할지는 **아직 결정 전**이며, 이번 요청 범위 밖입니다.
