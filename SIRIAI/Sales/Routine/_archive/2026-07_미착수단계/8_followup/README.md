# 8_followup — 후속·리마인더 (⬜ 설계)

## 1. 목적
회신이 **안 온** 발송 건을 1~2주 뒤 점잖게 **1회 리마인드**한다. 회신은 왔지만 며칠 진척 없는 리드, 미팅 임박/계약 마감도 챙긴다. 순서상의 단계가 아니라 **옆에서 매일 도는 감시역**(사이드 워처)이라 메인 흐름(5→6)에 끼어들지 않는다.

## 2. 두 흐름에서의 위치 (회신 온다 / 안 온다)
```
3 발송 → 4 추적 ─┬─ 회신 옴   → 5 회신·답장 → 6 제안대시보드 →[합쳐 회신]→ 7 미팅·계약
                 └─ 회신 없음 → 8 후속(여기) : N일 무응답 → 리마인드 1회 → 다시 4 추적
```
- 콜드메일은 1번보다 **2~3번 후속이 성과의 대부분**. 무응답을 사람이 못 챙기니 시스템이 챙긴다.

## 3. 데이터 계약
| 입력(6월) | 조건 | 출력(6월) |
|---|---|---|
| 발송단계=발송, 발송일자 | 발송 후 N일 경과 & 회신 없음 | 리마인드 초안 → 발송단계=후속대기, 후속횟수+1 |
| 발송단계=리드, 회신일자 | 회신 후 M일 정체 | 챙김 알림(후속 초안) |
| 발송단계=수신거부/제외 | — | 건드리지 않음(영구 제외) |

## 4. 메커니즘
- 매일 시트를 훑어 위 조건 행을 리스트업.
- 리마인드 초안은 **2_compose / 5_reply 톤·로직 재활용**(짧고 점잖게: "지난번 제안 보셨을까요?").
- 사람 검토 후 발송(자동발송 금지). 발송은 3_send 경로 재사용.

## 5. 안전·주의
- **과도한 후속 금지**(스팸·짜증 유발). 후속 **횟수 상한(예 1~2회)·최소 간격(예 7일)** 강제.
- 수신거부·거절 명시 건은 즉시 제외. 멱등(같은 건 중복 후속 금지 — 후속횟수로 가드).
- 발송과 동일하게 야간 금지·승인 게이트 적용.

## 6. 구현 메모
- 예상 파일: `run.py`(무응답 스캔 → 후속 대상 리스트 → 초안 생성), `config.py`(N일·M일·횟수·간격 상수).
- 시트 신규 칸 후보: `후속횟수`, `최종후속일자`.
- 결정 필요: 후속 간격·횟수(예: 발송 7일 뒤 1회, 14일 뒤 1회까지), 리마인드 문구 톤.
- 다른 모듈과 시트 열로만 연결(코드 의존 0).
