# 1_collector — 브랜드 리스트 → 공식 메일 자동 수집 (사이클 1단계) ✅ 가동 중

## 1. 목적·목표
구글시트 월별 탭(6월·7월…)의 **회사/브랜드명**을 읽어서:
- ① **공식 이메일 확보**(D열) — 콜드메일 보낼 주소
- ② **구분(카테고리) 분류**(B열) — 뷰티·리빙·F&B 등
- ③ **영업 대상 정리** — 제조사·중복뿐 아니라 **비화장품(예: 불스원=자동차용품)** 등 *보낼 수 없는/대상 아닌 행은 검증 후 과감히 삭제*. (메일 보낼 것 아닌 행이 쌓이면 리스트만 더러워짐)

목표: 매니저가 손으로 2시간 걸리던 "50개 서칭+이메일 찾기"를 명령 한 줄로. **핵심은 "보낼 수 있는 깨끗한 리스트"를 만드는 것.** (V1 = 이메일 확보까지. 발송은 모듈 `2_auto-send`.)

## 2. 구조
```
1_collector/
├── run.cmd / run.py   실행 진입점 (CLI). 예: .\run.cmd --inspect --tab 7월
├── logic/            이 모듈의 "두뇌" (판단 로직 4개)
│   ├── manufacturer.py        제조사 판별 (키워드+큐레이션, 보수적)
│   ├── category_overrides.py  구분 분류 보정사전 (마스터보다 우선)
│   ├── email_find.py          이메일 추출·개인메일 판별 헬퍼
│   └── email_findings.py      검증된 이메일 캐시 (※출처URL 필수 — 아래 기타)
├── PRD.md             상세 설계·결정 근거 (깊게 볼 때만)
└── archive/           과거 산출물·백업·일회성 스크립트 — 평소 안 봐도 됨 (4번 참고)
```
> 시트접근·백업·정규화는 여기 없고 `../_shared/`에 있다.

## 3. 기술 스택
- **Python 3.12** + 공유 `../.venv/` + `gspread`(서비스계정)
- 무거운 작업(분류·이메일 웹리서치)은 run.py가 직접 안 함 → **Claude Workflow 다중 에이전트**가 웹검색해 `tsv` 생성 → `run.py --fill-from`으로 시트 반영하는 **2단 구조**.
- 모든 쓰기는 **백업 → dry-run → `--apply --yes`**, 빈 셀에만.

### 주요 명령
```powershell
.\run.cmd --inspect --tab 7월        # 연결·헤더·구분분포·행별 보기
.\run.cmd --list-todo --tab 7월      # 구분/이메일 빈 행 목록
.\run.cmd --only category --tab 7월  # 구분 채움
.\run.cmd --prune --tab 7월          # 중복+제조사 삭제 후보(승인 후 삭제)
.\run.cmd --fill-from --file <tsv> --tab 7월   # 워크플로우 산출 tsv 반영
.\run.cmd --renumber --tab 7월       # A열 # 재번호
#  실제 반영은 끝에  --apply --yes
```

## 4. 기타 (아카이브·규칙·주의)
- **`archive/`** = 6월 작업의 산출물(reports·tsv·워크플로우 .js)·백업 CSV·일회성 스크립트(`_*.py`). **지워도 동작에 지장 없음** (기록용). 백업은 최신 2개 정도만 남기면 충분.
- **데이터품질 사고(2026-06-11):** `email_findings.py`에서 '앱솔브랩'에 토리든 이메일을 신뢰도 '높음'으로 오기재한 개체혼동 발생 → 정정함. **교훈이자 규칙:**
- **처리 규칙 (앞으로 준수):**
  1. 모든 이메일은 **출처 URL 필수**, 캐시 신뢰도 '높음'은 출처 있을 때만.
  2. 셀에 **업체명**이면 → **브랜드명으로 교체**+이메일(운영 브랜드 여러 개면 행 추가).
  3. **마스터 중복체크는 신뢰 근거로 쓰지 않음** — 인터넷 2차 확인이 우선.
  4. **미팅+계약성사** 기록 있는 브랜드는 매달 리스트에서 제거(재발송 방지).
  5. **새 월 탭** 생기면 직전 탭과 중복 제거.
  > 4·5번은 아직 코드에 없음 → 다음 작업(루틴화 전) 구현 대상.
