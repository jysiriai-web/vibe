# PRD — 루솜 (LUSOM) 인플루언서 캠페인 제안 대시보드

**프로젝트명:** 루솜 × SIRIAI 인플루언서 캠페인 제안  
**목적:** 신규 클라이언트 루솜에게 인플루언서 리스트 · 캠페인 구조 · SIRIAI 강점을 시각적으로 전달  
**전달 방식:** Vercel 배포 URL 링크 전송  
**파일 구조:** 단일 index.html (HTML + CSS + Vanilla JS)  
**배포:** 로컬 최종 확인 후 vercel --prod 단 한 번만

### 콘텐츠 (한 화면 fit 확인: 카드 3개 + 헤더 → 모달 없이 한 화면 구성 가능)

| 03 | 거품 없는 합리적 비용 | 플랫폼의 시스템 유지비·매몰비용은 고객 단가에 포함됨. SIRIAI는 린(Lean)한 조직으로 운영 → 플랫폼보다 저렴한 비용으로 무신사·HYBE 수준 결과물 납품. |
