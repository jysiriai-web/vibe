# 팀 공유 배포 (Vercel) — 5분 체크리스트

## 무엇이 어디서 되나

| | 대표님 PC (`dashboard.bat`) | 팀원 (웹 주소) |
|---|---|---|
| 모집·업로드·납품 보기 | ✅ | ✅ |
| 링크·닉네임·팔로워 수정 | ✅ | ✅ |
| 검수 드롭다운·확정안내·★베스트 | ✅ | ✅ |
| 모집시트 동기화 | ✅ | ✅ |
| 정산 시뮬레이터 | ✅ | ✅ |
| **모집 스캔 / 업로드 스캔** | ✅ | ❌ (버튼 안 보임) |
| **가드닝 — 집행·비용 (돈)** | ✅ | ❌ (탭 자체가 안 보임) |

- 팀원이 고친 건 **곧바로 마스터 시트**에 들어갑니다. 대표님 대시보드에도 똑같이 보여요.
- 클라우드에는 **smmkings 키를 올리지 않습니다.** 돈 기능이 아예 없으니 필요가 없어요.

---

## 대표님이 하실 것

### 1. Vercel 프로젝트 만들기
1. [vercel.com](https://vercel.com) 로그인 → **Add New… → Project**
2. GitHub 저장소 **`jysiriai-web/vibe`** 선택 → Import
3. ⚠️ **Root Directory** 를 반드시 **`SIRIAI/Campaign/댄스캠페인`** 으로 지정 (Edit 눌러서 변경)
4. Framework Preset: **Other** (자동으로 잡힐 거예요)

### 2. 환경변수 2개 넣기 (Settings → Environments → Production)

| 이름 | 값 |
|---|---|
| `GARDEN_STATE` | `sheet` |
| `CAMPAIGNS_JSON` | `_docs/vercel-CAMPAIGNS_JSON.txt` 파일 내용 통째로 |

> **넣지 말 것**: `SMMKINGS_API_KEY`, `EXECUTE_PASSWORD` — 클라우드엔 돈 기능이 없어서 불필요하고, 안 올리는 게 안전합니다.

`CAMPAIGNS_JSON` 은 `_docs/vercel-CAMPAIGNS_JSON.txt` 를 메모장으로 열어 전체 복사.
(이 파일엔 시트 주소·토큰이 들어 있어 **git에 안 올라갑니다.**)

### 3. Deploy 누르기
끝나면 주소가 나옵니다. 팀원에게 **주소만** 알려주면 돼요 — 비번 없이 바로 들어갑니다.

> 팀 URL 은 비번이 없습니다(대표님 결정). 대신 **돈 나가는 기능은 클라우드에 아예 없습니다** —
> 집행·종료·포기·스캔은 서버가 501 로 거절하고, smmkings API 키도 Vercel 에 올라가 있지 않습니다.
> 즉 URL 을 아는 사람이 볼 수는 있어도 지출을 일으킬 수는 없습니다.

## 평소 흐름

1. **대표님**: `dashboard.bat` 실행 → **모집 스캔 / 업로드 스캔** → 결과가 시트에 저장됨
2. **팀원**: 웹 주소 접속 (비번 없음) → 링크 고치고, 검수하고, 확정안내 체크
3. **대표님**: 가드닝 필요한 계정 확인 → **집행**(비번 `0907`) — 로컬에서만

## 문제 생기면

- 팀원 화면이 안 뜬다 → Vercel 환경변수 4개가 다 들어갔는지 확인 (특히 `CAMPAIGNS_JSON`)
- 팀원이 수정했는데 대표님 화면에 안 보인다 → 새로고침 (둘 다 같은 시트를 봄)
- 되돌리고 싶다 → Vercel 프로젝트 삭제. 로컬 대시보드는 아무 영향 없음

## 나중에 (선택)

- 브릿지 토큰(`appsscript/Code.gs` 의 `TOKEN`)이 저장소에 들어 있습니다. 비공개 저장소라 당장 문제는 없지만, 신경 쓰이면 새 값으로 바꾸고 → 브릿지 재배포 → `CAMPAIGNS_JSON` 갱신 순서로 교체하면 됩니다.
