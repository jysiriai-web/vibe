# 📁 폴더 재구성 제안 — `Garden` → 멀티캠페인 시스템 이름 맞추기

> 야간 1단계에서 빠졌던 문서입니다. **아침에 대표님과 함께 실행**하기 위한 제안서예요.
> ❌ **야간에 실제 폴더 rename·파일 이동은 하지 않았습니다(하면 안 된다고 하셨고, 실제로 안 했어요).** 이 문서는 계획일 뿐이고, 손대면 라이브 Vercel 배포가 깨집니다.
> 원칙은 그대로예요 — **"쉬워야 한다 / 뺄 수 있으면 뺀다."** 그래서 아래도 *꼭 필요한 것(폴더명)* 과 *선택(내부 재편)* 을 분리했어요.

---

## 1. 지금 상태 (직접 훑고 확인한 사실)

**폴더 트리 (Garden/)**
```
Garden/
├─ src/            백엔드(Node 내장 http, 의존성 0) — server.js·campaigns.js·smm.js·sheet.js·tiktok.js …(21개)
├─ public/         프론트(대시보드 UI·정산 시뮬레이터) — index.html·app.js·style.css …
├─ scripts/        CLI 도구 — sync·execute·orders·scan-content·verify-smm …
├─ appsscript/     구글시트 브릿지(Code.gs·lun8_setup.gs) — 시트에 배포하는 코드
├─ api/            Vercel 서버리스 진입점(index.js → src/server.js 재사용)
├─ data/           캠페인별 상태(orders·smm-services·scan-latest …)   [gitignore]
├─ campaigns.json  캠페인 설정(시트 URL·토큰·목표·서비스)            [gitignore·비밀]
├─ .env            smmkings 키·시트 토큰                             [gitignore·비밀]
├─ vercel.json / package.json / dashboard.bat
├─ .claude/launch.json   (미리보기용 dev 서버 정의)
├─ _bat/ _docs/ _archive/ featuring_emails/ _overnight/  (유틸·문서·과거·이메일수집·야간산출물)
```

**중요한 배선 3가지 (재구성이 건드리는 급소)**
- **상위 repo 관계** — VIBE 전체가 **단일 git repo**(root: `C:/Users/whwns/Desktop/VIBE`). Garden은 **서브모듈/서브트리가 아니라 그냥 하위 폴더**예요(`.gitmodules` 없음 확인). → 브리프의 "git 서브트리" 우려는 **해당 없음**. rename은 평범한 tracked 이름변경입니다. (다만 함정 하나 있음 — 4번 참조)
- **Vercel 배포 root** — `_docs/팀공유_배포.md` 기준, Vercel 프로젝트의 **Root Directory = `SIRIAI/Campaign/댄스캠페인`** 로 지정돼 있어요. 이건 **repo 안이 아니라 Vercel 대시보드 설정**입니다. → 폴더명을 바꾸면 **여기도 같이 바꿔야** 배포가 안 깨져요. (제일 중요한 급소)
- **코드의 경로 해석 방식** — `src/`·`scripts/` 의 파일은 전부 `root = dirname(dirname(import.meta.url))` 로 루트를 **상대적으로** 계산해요. 코드 어디에도 `"Garden"` 문자열이 하드코딩돼 있지 않습니다. → **최상위 폴더 이름만 바꾸는 건 코드가 안 깨져요.** 반대로 **내부 폴더 depth/이름을 바꾸면** `join(root,'public')`·`join(root,'data')`·`import '../src/server.js'` 같은 곳이 깨집니다.

## 2. 왜 바꾸나 (문제)

폴더명 `Garden`(🌱 가드닝)은 **초기 기획(팔로워 보충=가드닝)** 의 잔재예요. 지금 이 폴더는 **인플루언서 캠페인 전주기(모집→업로드→가드닝→납품→정산)를 여러 캠페인(베이온·LUN8…)에 대해 굴리는 멀티캠페인 대시보드 시스템**으로 커졌습니다. "가드닝"은 이제 5개 탭 중 **하나**일 뿐이라, 이름이 범위를 오해하게 만들어요.

## 4. 제안 B — 내부 구조 재편 (선택, 고위험 — 나중에/원할 때만)

브리프에 요청된 `server/·web/·apps-script/…` 안을 그려는 뒀지만, **원칙(쉬워야 한다·절제)에 비추면 지금 당장은 권하지 않아요.** 현재 내부 구조(`src`·`public`·`scripts`·`appsscript`)는 이미 깔끔하고, 이름을 바꾸는 순간 **아래 10곳의 배선을 동시에 손대고 재검증**해야 합니다. 이득(이름이 조금 더 예쁨) < 위험(라이브가 조용히 깨짐). → **B는 "언젠가 팀이 헷갈릴 때" 여는 옵션**으로 두는 걸 추천.

그래도 요청하셨으니 목표 트리와 이동 맵을 남깁니다:

```
campaign-hub/
├─ server/         ← 현 src/        (백엔드; depth 반드시 1 유지)
├─ web/            ← 현 public/     (프론트; vercel.json outputDirectory 동시수정)
├─ cli/            ← 현 scripts/    (수동 CLI 도구)
├─ apps-script/    ← 현 appsscript/ (시트 브릿지)
├─ api/            (그대로; Vercel 진입점)
├─ worker/         ← 현 _overnight/agent/  (스캔 자동화 에이전트 — 프로토타입이 정식 승격되면)
├─ campaigns/      캠페인 설정 묶음: campaigns.json + 캠페인별 data/ 를 여기로 모을지 검토
├─ data/           (그대로; 런타임 상태)
└─ _docs/ _bat/ _archive/
```
**이동 맵 요약:** `src→server`, `public→web`, `scripts→cli`, `appsscript→apps-script`, `_overnight/agent→worker`. `featuring_emails/`(이메일 수집)는 이 시스템과 결이 달라 → **Routine 쪽으로 이관하거나 `_archive/`** 로 빼는 걸 별도 검토.

## 5. ⚠️ 깨지는 것 목록 + 안전한 실행 순서

### 방법 A만 할 때 (최상위 폴더명만 변경) — 깨지는 것
1. **Vercel Root Directory 설정** (`SIRIAI/Campaign/댄스캠페인` → `SIRIAI/campaign-hub`) — 대시보드에서 **수동으로** 바꿔야 함. 안 바꾸면 배포 실패. **(1순위 급소)**
2. **git mv 함정** — `.env`·`campaigns.json`·`data/`·`.claude/`·`_archive/`·`node_modules/` 는 **전부 gitignore(untracked)**. `git mv` 는 tracked 파일만 옮겨서 **비밀·데이터를 그 자리에 버리고 감.** → 반드시 **OS 이름변경(탐색기/`mv`)으로 통째 옮긴 뒤 `git add -A`** 로 tracked 리네임을 기록. (거꾸로 하면 안 됨)
3. **Claude Code 스크래치패드/세션 기록** — 폴더 경로(`…-Garden`)를 키로 잡아서, rename 후엔 새 경로(`…-campaign-hub`)로 **새 버킷**이 생겨요. 임시파일 연속성만 잃고 큰 문제는 아님. (참고: **auto-memory는 VIBE 루트 키라 그대로 유지** — 안 잃어요.)
4. **바탕화면 바로가기/북마크** — `dashboard.bat` 로의 바로가기가 있으면 경로가 깨짐(파일 자체는 폴더 따라 이동).
5. **문서 후속(안 깨지지만 갱신)** — README 제목(🌱 Garden), `package.json` name(`siriai-garden`), 메모(`project_siriai_garden.md`의 `Garden/` 언급).

> **안 깨지는 것(A):** `.claude/launch.json`(상대인자)·`dashboard.bat`(`cd /d %~dp0`)·`vercel.json`·`api/index.js`·`src`/`scripts` 내부 경로(`import.meta.url`) 전부 그대로 동작.

### 방법 B까지 할 때 — 추가로 깨지는 것 (내부 이름/경로)
1. `root = dirname(dirname(import.meta.url))` — **폴더 depth를 1로 유지**해야 함(예: `server/src/…` 로 더 깊이 넣으면 루트 계산이 어긋남).
2. `join(root,'public')` (server.js:27) — `public→web` 시 문자열 수정 + **`vercel.json` outputDirectory** 동시수정.
3. `join(root,'data', …)` (server.js·campaigns.js·scripts 다수) — `data/` 이름 바꾸면 전부 수정.
4. `join(root,'campaigns.json')` (campaigns.js) — campaigns.json 을 `campaigns/` 로 옮기면 수정.
5. `api/index.js` 의 `import '../src/server.js'` — `src→server` 시 수정.
6. `vercel.json` rewrite(`/api → /api/index`)·outputDirectory — `api`/`public` 손대면 수정.
7. `.claude/launch.json` `runtimeArgs:["src/server.js"]` — `src` 이름 바꾸면 수정.
8. `dashboard.bat` `node src/server.js` — 수정.
9. `package.json` scripts(`node src/server.js`·`node scripts/…`) — 수정.
10. `.gitignore`·README 트리 — 수정.
→ **총 ~10곳을 원자적으로 고치고, 반드시 로컬 실행 + Vercel 프리뷰로 재검증.**

- [ ] 0. **현재 Vercel Root Directory 값 메모** + working tree 커밋해서 깨끗하게(롤백 대비).

### 롤백 (문제 생기면)
