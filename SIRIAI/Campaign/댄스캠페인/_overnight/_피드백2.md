# LUN8 대시보드 목업 — 2차 피드백 (2026-07-16, 목업 본 후)

현재 `_overnight/lun8_wakku.html`(1차 반영본)을 이 피드백대로 더 고칠 것. 정정(⚠️) 주의.

## 로고·상단
1. **로고 교체**: 🌱 새싹 → **SIRIAI 로고**(검은 원 + 흰 추상 마크: 대각선 물방울 2개 + 작은 타원). 정확한 파일 없으면 인라인 SVG 근사 재현(나중에 실제 파일로 교체 가능하게).
   - 사이드바 부제 **"마루 × 시리아이" → "댄스챌린지"** (SIRIAI / 댄스챌린지).
2. **캠페인 링크 옆에 '마스터시트 링크'** 버튼(구글시트 바로 열기).
3. **상단 stats 재구성**: `모집 N명` · `업로드 N명` · `검수완료 총 N명` · `마지막 스캔` · `설정`. (기존 잡다한 것 대신 이 5개.)
4. **인원 추가 버튼이 과하게 큼** → 일반 크기로 축소.

## 표·정렬
5. **정렬 없음** → 각 열 헤더 클릭 시 오름/내림차 정렬 추가.

## ⚠️ 상한 정정
6. **모집 탭 = 모집 인원 상한 없음**(무제한 모집). 상한은 **업로드/검수**가 목표 기준, **정산 상한 = 105건**(목표 100 + 오버부킹 5). 오버부킹은 정산에 적용되는 개념.

## ⚠️ 요약 정정 (건 vs 명 — 1명이 여러 콘텐츠라 다름!)
7. 요약을 이렇게:
   - **모집 인원 = 총 N명** (틱톡 N / 인스타 N) ← **명(사람)**
   - **진행사 = 마루 N건 / 시리아이 N건** ← **건(콘텐츠)**
   - **플랫폼 = 틱톡 N건 / 인스타 N건** ← **건**
   - '명'과 '건' 라벨을 명확히 구분해서 표기.

## 가드닝 (정정·중요)
8. **충전량 = 베이온 방식 참고**(`src/garden.js`의 classify/order 로직). 지금 목업의 "360" 식 고정값 틀림 — 베이온은 목표(min, 예 1000)까지 필요한 만큼 충전. 실제 로직 확인해서 반영.
9. **가드닝 필요 없는 사람은 목록에 아예 안 띄움**(대상만 보이게).
10. ⚠️ **가드닝 대상 판단 로직**(내 이전 "미업로드 확정자 제외"는 오해 — 폐기):
    - 실제: 마루 등에서 25건 목표로 30명을 보냄(드랍 대비 초과). 그중 **마감 임박 + 업로드 확률 낮다 판단되는 사람은 미리 가드닝 안 함** → **업로드되면 그때 가드닝**.
    - 즉 업로드했거나 확률 높은 사람 우선 가드닝, 불확실한 사람은 업로드 확인 후로 보류. (자동 확정 제외 X, '보류/대기' 개념.)

## 납품
11. **납품시트 = 인스타/틱톡 따로**(아직 안 만듦, 아마 한 구글시트 안에 하단 탭 2개). 납품 기능이 **플랫폼별 탭**을 고려하게(틱톡 납품 / 인스타 납품).

## 편집
12. **각 탭별로 개별 편집** 가능하게 구성(탭마다 행 편집 독립적으로).

## 정산·마진 시뮬
13. 마진 시뮬에 **진행사별 정산액** 반영: **마루 = 콘텐츠당 6,000엔**, **시리아이 = 5,000엔**(단 시리아이는 추천/우수 보너스 있음). 마진 계산에 이 원고료 원가 넣기.
14. **정산 방식 = 아마존 / 구글 / 애플** 등(기프트카드 종류)으로 드롭다운. (현금/기프트카드 X)
