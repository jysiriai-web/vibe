팔로워 스캔5~10분대기
틱톡대기
인스타대기
이게 뭐죠?

두 플랫폼의 팔로워·닉네임을 마스터시트에 채워요. 세션이 서로 달라 동시에 돌아갑니다.
지원자를 가져오는 기능이 아니에요 — 그건 대시보드의 [모집 가져오기]예요.
틱톡은 크롬 창이 뜨면 로봇 인증만, 인스타는 처음 한 번 로그인이 필요해요.

업로드 스캔5~15분대기
틱톡대기
인스타대기
이게 뭐죠?

두 플랫폼에서 영상을 올렸는지 확인하고 콘텐츠 링크·해시태그·조회수를 채워요.
틱톡은 로봇 인증을 끝낸 뒤 [스캔 시작]을 눌러야 진행돼요.
인스타 음원은 자동 판정이 안 돼요(릴스는 지정 음원도 '오리지널 오디오'로 표기) — 음원만 사람이 확인합니다.

성과 갱신5~15분대기
틱톡대기
인스타대기
이게 뭐죠?

이미 올라온 콘텐츠의 성과를 다시 읽어 마스터시트에 채워요. 업로드 여부를 새로 찾지는 않아요 — 그건 [업로드 스캔]입니다.
· 틱톡 — 조회수. 납품시트 비고의 '12000조회수' 표기가 여기서 나와요(1만 이상만).
· 인스타 — 좋아요·댓글. 조회수는 인스타가 안 줍니다(프로필 API 는 늘 0, 릴스 페이지에도 재생수 표기가 없어요 — 로그인 상태로 확인). 필요하면 시트에 직접 적어야 해요.
예전엔 인스타가 한 번 찾은 뒤로는 다시 안 봐서 좋아요·댓글이 첫 값에 얼어 있었어요(시트 3인데 실제 24).
틱톡 브라우저를 쓰기 때문에 다른 스캔이 도는 중엔 못 눌러요. 로봇 인증을 끝낸 뒤 [스캔 시작]을 눌러야 진행돼요.

가져온 뒤에는 대시보드에서 ↻ 새로고침 을 눌러야 화면에 보여요.

패널 확인 필요 = 주문번호를 못 받은 건. 패널에서 실제로 들어갔는지 확인한 뒤 [확인함]을 누르면 그 계정에 다시 주문할 수 있게 열려요.
수기 집행 = 손으로 넣은 주문. 다 채워졌으면 [완료 처리]로 닫아요.
돈은 안 나가요 — 장부만 고칩니다.
