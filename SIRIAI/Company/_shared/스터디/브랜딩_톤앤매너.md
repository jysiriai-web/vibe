## 0. 한 줄 제안
> ### "명료한 에디토리얼 아카이브" — Clear · Archival · Precise
> 친절한 명료함 × 기록의 에디토리얼(sa:ai Archivo) × AI의 정밀. (신비는 톤으로만, 정보는 명료하게)

## 3. 구체 제안

### 3.1 무드 키워드
> 조용함(Quiet) · 신비(Mystic) · 기록(Archival) · 정밀(Precise) · 관계(知り合い)

### 3.2 컬러
- **베이스:** 화이트 `#FFFFFF` ~ 오프화이트 `#FAFAF8`
- **잉크:** `#111111` (텍스트·강조)
- **그레이 스케일:** `#666` `#999` `#E5E5E5` (보조·라벨·구분선)
- **포인트:** 색은 **콘텐츠(이미지·썸네일)가 부여** (회사소개서 원칙). UI는 무채색 유지.
- *[옵션]* 아주 미묘한 액센트 1색 (예: 딥 잉크블루 / 웜 골드 — `siriai_teumgyul.html`이 골드 톤이었음)

### 3.3 타이포 (한글 위주 — 대표님 결정 반영)
- **헤딩:** 한글 **명조(serif)** — Noto Serif KR / 본명조. → "New Editorial", 신비·사유
- **바디:** 한글 **산스** — Pretendard(권장, 한국 웹 표준급) / Noto Sans KR. → 가독·정밀
- **영문 포인트:** 그로테스크 산스 — Inter / Suisse 계열. → 홈과 톤 일치
- 대비: 헤드 크게(여백 충분) + 바디 차분. uppercase 라벨로 'index' 느낌.

### 3.4 레이아웃 — "Archival Index"
- 섹션마다 **번호(01·02…) + uppercase 라벨(eyebrow) + 주석**. = 기록/색인 감성.
- 충분한 여백, 단일 스크롤 에디토리얼.
- **Partners** = 8division식 텍스트 리스트(전체 나열, 대표님 결정). 
- **데이터/실적** = 그리드 + 라벨로 '아카이브'처럼. (sa:ai Archivo와 시각 통일)

### 3.5 인터랙션
- **fade-in on scroll만.** 애니메이션 최소(회사소개서 원칙). 차분·느림.
- 마이크로 인터랙션은 절제 (호버 시 미묘한 톤 변화 정도).

## 4. ✅ 확정된 방향 (2026-06-02)
- **무드:** 정보·명료 우선 (읽기 쉽고 친절하되, 명조+모노크롬으로 절제된 품위)
- **헤딩:** 한글 **산세리프(Pretendard)** — 팀장님 홈과 톤 통일 *(deck은 홈 플로팅으로 진입하는 독립 페이지라 일관성 우선. 명조 폐기)*. 에디토리얼 느낌은 여백·라벨·Archival Index로.
- **컬러(2026-06-02 홈 실물 확인 후 변경):** 홈과 동일 — **화이트 골격 + Hero 파스텔 그라데이션**(베이지·라벤더·피치) + 가는 flow 라인. 색은 **섹션별 강한 비주얼 카드(이미지)가 부여.** UI 텍스트는 잉크/그레이. *(순수 모노크롬 → 홈 통일로 변경)*
- **레이아웃:** **Archival Index**(번호·라벨·주석) + 홈식 **좌측 텍스트 / 우측 강한 비주얼 카드**. sa:ai Archivo·데이터와 시각 통일
- **인터랙션:** fade-in only, 차분
→ 한 줄: **명료한 에디토리얼 아카이브.** 명조 헤딩 + 모노크롬 + 색인 구조.
