[global seeding — 02 비주얼 콘텐츠 상세 화면 구성안]

이 서비스(global seeding)를 deck에서 클릭했을 때 펼쳐지는 '상세 화면'에 들어갈 내용입니다.
위에서 아래로 읽는 순서이고, 각 블록은 [제목 + 본문 + 이미지 자리(개수/종류/위치)]로 구성됩니다.
텍스트는 실제 들어갈 카피 초안이고, 이미지는 '몇 장, 어떤 컷이, 어디에' 들어가는지를 표시했습니다.
(아직 초안 — 확인하고 고칠 부분 말해주면 반영)

============================================================

01 — 인트로

제목: 세계 곳곳의 진짜 후기로, 데뷔합니다
본문: 시리아이의 글로벌 시딩은 총 75개국을 대상으로, 각 나라의 SNS 문화에 맞춰 현지 인플루언서가 진짜 사용 후기를 만들도록 설계합니다. 신규 시장에 '아는 사이'로 진입하는 가장 직접적인 방법입니다.

이미지: 1장
- 종류: 대표 비주얼 (글로벌 시딩 콘텐츠 모음 / 권역 무드)
- 위치: 제목/본문 아래 가로 풀폭 1장
- ※ capture 폴더에 기존 캡처 다수 → 그중 1컷 선별

============================================================

02 — 규모 · 커버리지

제목: 75개국, 12개 이상의 플랫폼
본문: TikTok·Instagram·YouTube·샤오홍슈 등 12개 이상의 콘텐츠 플랫폼 위에서, 나노 인플루언서를 중심으로 숏폼 시딩을 운영합니다.

이미지: 1장
- 종류: 다이어그램 (커버리지)  [제작 완료: 이미지_커버리지.svg]
- 위치: 본문 아래 풀폭 1장

============================================================

03 — 콘텐츠 타입 · 지정

제목: 원하는 결로, 정확히 지정해서
본문: 리뷰·튜토리얼·챌린지·비포&애프터 등 브랜드 니즈에 따라 콘텐츠 형태를 커스터마이징하고, 성별·연령·국가·콘텐츠 타입까지 지정할 수 있습니다.

이미지: 1장
- 종류: 다이어그램 (콘텐츠 타입)  [제작 완료: 이미지_콘텐츠타입.svg]
- 위치: 본문 아래

============================================================

04 — 플랜

제목: 두 가지 플랜, 최소 수량 제한 없이
본문: 인플루언서 등급에 따라 Standard(ENGAGE+)·Premium(ENGAGE++) 두 플랜으로 운영되며, 최소 수량 제한 없이 유연하게 진행합니다. 콘텐츠 IP(2차 활용권)는 별도로 확보할 수 있습니다.

이미지: 0~1장 (선택 — 플랜 2단 비교, 단가 없이)
- ※ 단가(5만/10만)는 deck 비노출. 내부 자료에만 두고, 화면엔 '두 플랜·최소수량 없음'까지만.

============================================================

05 — 진행 프로세스

제목: 복잡한 기존 방식과 다르게, 단순하게
본문(6단계): 계약 → 1.5배수 리스트 제공 → 컨펌·발송 → 업로드 전담 관리 → 완료 기준 정산 → 실시간 보고서
- 업로드 완료 기준으로 정산해 비용 손실을 최소화하고, 실시간 온라인 보고서로 성과를 추적.

이미지: 1장
- 종류: 다이어그램 (프로세스)  [제작 완료: 이미지_프로세스.svg]
- 위치: 본문 아래 가로 풀폭 1장

============================================================

06 — 차별점

제목: 매칭을 넘어, AI와 현지화로
본문: 단순 매칭이 아니라, AI 기반 인게이지먼트 분석과 글로벌 현지화 전략으로 브랜드와 고객의 연결 가능성을 실질적으로 확장합니다.

이미지: 0~1장 (선택)
- 종류: sa:ai 분석 화면 자리 (03 sa:ai와 연계)

============================================================

07 — 사례 (선택)

제목: 실제로 이렇게 돌렸습니다
본문: 익명 케이스 — 업종 / 목적 / 한 것 / 결과

이미지: 2~4장
- 종류: 실제 진행 콘텐츠 캡처 (capture 폴더 활용)

============================================================

[이미지 총량 정리]
- 제작 완료(다이어그램): 커버리지 1 + 콘텐츠타입 1 + 프로세스 1 = 3장
- 실제 캡처(capture 폴더 활용): 인트로 1 + 사례 2~4 = 3~5장
→ 권장 6~8장

[비고]
- global seeding/capture 에 기존 캡처 30여 장 있음 → 인트로·사례 컷은 여기서 선별하면 됨.
- 단가(5만/10만)는 deck 비노출 — 내부 자료에만.
