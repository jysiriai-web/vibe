## 2. 포지셔닝 재정의 — 야심찬 확장

### 2.1 한 문장 정의
> **시리아이는 검증된 마케팅 실행력과 자체 AI 기술, 두 축으로 브랜드의 성장을 설계하는 그룹이다.**
> 인플루언서·콘텐츠·오프라인에서 증명한 실행력과, sa:ai·PB의 기술 비전 — 둘 다 당당히. (知り合い = 시장과 클라이언트를 잇는 '아는 사이')

### 2.2 "마케팅 = 입구 / 아키텍처 = 목적지" 모델
```
   [입구]                          [목적지]
콘텐츠·인플루언서 마케팅  ──→  브랜드 비즈니스 구조 설계
(지금 매출의 주력,            (진짜 야심: 기술·PB까지)
 가장 강한 레퍼런스)
   증거 ─────────────────────→ 비전
```
방문자는 **마케팅으로 들어와서, 아키텍처 그룹임을 납득하고 나간다.** 처음부터 "우리 기술 회사예요" 하면 증거가 없어 공허하고, 끝까지 마케팅만 말하면 단순 마케팅 회사로 주저앉음.

### 2.3 "아키텍처 그룹"이라 주장할 **자격(증거)**
최대 리스크는 *"말만 거창한 거 아냐?"*. 이걸 막는 4개의 증거 기둥:

| 기둥 | 증거 | 섹션 |
|---|---|---|
| ① **브랜드를 직접 운영해봤다** | 패션 플랫폼 직접 운영 → 분사한 기술팀 | Structure (§5.7) |
| ② **마케팅이 자체 기술 위에서 돈다** | AI 크롤링·스코어링 (인스타 전체가 DB) | Architecting (§5.2) |
| ③ **압도적 실행 실적** | 700만급 메가·HYBE 아티스트·나노 94.6%·종합 캠페인 (성과보고서·익명화) | Partners·Case (§5.6) |
| ④ **우리 브랜드도 만든다** | PB / Product (26년~) | Practice 04 (§5.5) |

→ 모든 섹션은 이 4기둥 중 하나를 증명하도록 배치.

### 2.4 톤 & 디자인 원칙
- 신비주의 / 영어 베이스 / 차분함·느림 / 화이트톤 / 애니메이션 최소
- 카피는 **선언적 + 12랩스식 "기술 번역"** (어려운 걸 쉬운 메타포·비즈니스 결과로)
- 모든 동사는 **주체적 동사** ("설계한다·진단한다·발굴한다·구축한다"). "제작해드립니다" 류 벤더 언어 금지
- 이미지 최소, 텍스트 에디토리얼
- 팀장님 홈(`AI consulting studio`, 화이트·monopo톤)과 톤 일관 유지
- **포지셔닝 = 두 기둥 병행**(대표님 결정): 마케팅 실행력 + 기술 비전을 동등하게. 어느 하나 약화 안 함.
- **실적 노출 = 익명화 수치 원칙**(대표님 결정): 실명·단가 대신 "700만급 메가·HYBE 아티스트·방문률 94.6%·나노 191 DB" 같은 급·수치로. (성과보고서 대외비)
- **톤앤매너 확정**([`브랜딩_톤앤매너.md`](브랜딩_톤앤매너.md)): 한글 **산세리프(Pretendard, 홈과 통일)** + **모노크롬**(색은 콘텐츠가) + **Archival Index** 레이아웃 + **정보·명료** 우선 + fade-in only. + 기술스택(OpenAI·Anthropic·Vercel 등) sa:ai에 노출. = "명료한 아카이브 + 홈 톤 통일"

## 3. 타겟 & 설득 전략 — semi-warm 방문자

**방문자 정의:** 팀장님 홈을 거쳐 온, **이미 관심이 생긴 사람** (콜드 아님). 미팅·영업 맥락에서 직접 링크를 건네는 경우 포함.

| 콜드라면 (X) | semi-warm이라서 (O) |
|---|---|
| 첫 화면부터 신뢰 증거 융단폭격 | 비전·관점부터 당당히 |
| "뭐하는 회사인지" 친절 설명 | "왜 우리가 다른지" 차별·야심 |
| 전환 = "일단 알아보기" | 전환 = **"같이 큰 그림 그려보자"는 명분** |

**핵심:** "이 회사 괜찮나?" 증명이 아니라, **"이 팀과 함께라면 멀리 가겠다"는 확신 + 연락할 명분**.

> **⚠️ 더 중요한 조정 (홈 분석 후):** 팀장님 홈에 이미 Four Practices "소개"가 있음 → 우리 Deck이 또 소개하면 중복. **"소개형"을 "증명형"으로 재구성** 필요. ([`사업소개서_필요사항.md`](사업소개서_필요사항.md) §0)

### 4.3 "회사 소개 → 1·2번만" 해석
4개를 다 보여주되 **위계**를 둠:
- **01·02 = 활성·주력** (구체 서비스·프로세스, 클릭 시 상세)
- **03 sa:ai = 기술 엔진** ("우리 마케팅이 도는 기반" + 외부 솔루션 확장. 상세 🔴)

> v0.1의 "1·2번만, 3·4 흐림"은 옛 발상이라 폐기. 야심찬 확장에선 3·4가 오히려 포지셔닝의 핵심 증거.
