# SIRIAI 랜딩페이지 — Claude Design 킥오프 브리프

> **쓰는 법:** Claude Design(claude.ai)에서 새 대화 → ① 찾은 **레퍼런스 이미지**들 + ② 현재 파일 **`DECK/_demos/cand-minimal.html`**(코드/스크린샷) 첨부 → ③ 아래 전체를 붙여넣고 **"먼저 히어로부터"** 요청.
> 한 줄: **"챗봇형 좌우 2단 인터랙티브 세일즈 랜딩. 구조·인터랙션·브랜드토큰은 고정, 너는 '비주얼'을 올린다. 최우선 = 진짜 심플 + SIRIAI다움(감성+테크니컬) + 첨부 레퍼런스 톤. 이번 1순위 = 히어로 비주얼 임팩트."**

---

## 0. 무엇인가
SIRIAI(시리아이, 知り合い='아는 사이' — 인플루언서 마케팅/크리에이터 콘텐츠)의 **세일즈 콜드메일 링크용 랜딩페이지**. 사업소개서(deck) 아님. 메일 받은 브랜드 인하우스 마케터가 클릭해 들어와 **"어 좀 다르네 / 안 복잡하네 / 우리도 스무스하겠네"**를 느끼고 연락하게 만드는 것. 아무도 100p 안 읽는다 → **경험·인터랙션**으로.

## 1. 절대 가치 (디자인 판단 기준)
1. **진짜 심플** — 정보·텍스트·요소 최소가 미덕. 안 넣어도 되면 뺀다. (화면에 글/박스/숫자 늘리지 말 것)
2. **감성 + 테크니컬 동시** — 차분·감각적 여백(감성) + 정밀·구조(테크). 한쪽만이면 실패.
3. **테크니컬의 재정의** — "그래픽이 좋은 것"이 테크니컬이 아니다. **브랜드 페인포인트·프로세스를 정확히 이해하고 깔끔히 설명·구조화하는 것**이 테크니컬. 챗봇 형식 자체가 테크니컬 → 그 경험을 더 세련되게.
4. **여유의 톤** — "우리 지린다"가 아니라 **"아무렇지 않게 사업 잘 진행하고 있다"** + "당신의 페인포인트를 이미 이해하고 있다". 과시·벤더톤 금지.
5. **느린 무드** — 전환·모션 전부 슬로우(0.8~1.2초대), 차분. 분주함 금지.
6. **경험적** — 고르면 그 자리서 펼쳐지는 것. 리스트/FAQ/채팅타이핑 느낌 금지.
7. **홈페이지와 한 결** — 배포 홈페이지 톤(에디토리얼·웜워시·모노라벨). 단 홈페이지처럼 정보 많아지면 안 됨(랜딩=극도 절제).

## 2. 브랜드 토큰 (무조건 준수)
- 배경 **Paper `#f3eee2`** · 텍스트 **Ink `#211a33`** · 보조 `rgba(33,26,51,.74)` · 캡션 `.56` · 헤어라인 `.13`.
- **웜워시(색의 유일 출처, 평면 원색 금지)**: peach `rgba(246,201,168,.5)`, lilac `rgba(221,208,239,.45)`. 기본 배경 = radial(peach 16% 6%) + radial(lilac 88% 4%) + Paper. 액센트는 전부 이 두 색 + ink 파생 **저채도**.
- 폰트: 국문·본문 **Pretendard**, 영문 **Arimo/Helvetica**, 라벨 **JetBrains Mono**(UPPERCASE, letter-spacing .18em), 세리프 악센트 **Bodoni Moda**(아주 드물게, 라틴/숫자에만 — 한글에 이탤릭 세리프 금지=폴백 깨짐).
- 강조 = **Ink 솔리드 알약 '하나'만**. 라운드 14/18/100. 그림자 단일 `0 16px 44px rgba(33,26,51,.13)`.
- ⛔ Schibsted Grotesk/Inter/Roboto/Arial단독 · 순백텍스트면 · 순흑 · 형광/무지개 · 이모지 · 진한그림자 금지. 국문 `word-break:keep-all`.

## 3. 확정 구조·동작 (★고정 — 비주얼만, 구조/JS 바꾸지 말 것)
- **인트로**: "SIRIAI가 [브랜드]의 고민을 해결해 드립니다." + 시작. (`?b=`면 브랜드명, 없으면 '당신의') → 슬로우 전환으로 메인 진입.
- 메인 = **좌우 2단**. **왼쪽 = 히어로 질문 5개(항상 고정 노출, ~32% 컬럼)** + 하단 브랜드 한마디 + 미니 푸터. **오른쪽 = 답.** ⛔ 사이드바 접힘/오버레이/rail **전면 폐기**(죽은 공간·깨짐 유발) — 다시 만들지 말 것.
- 질문 클릭 → 오른쪽: **제목 떠오르고 + 본문만 타이핑**(차분, ~27ms). 첫 '한 호흡'은 보장 타이핑, 이후 클릭하면 즉시 완성(스킵), 안 누르면 끝까지. 패널 전체 페이드 금지.
- 답변 밑 **"이어서 물어보기"** 후속질문 체인(2~3뎁스) → **후속 3번 클릭 후 연락(협업제안 mailto + 오픈채팅) + 포폴 링크** 등장(너무 일찍 X).
- **정보의 층위(특정 질문만)**: 해외 질문은 후속이 **미국/중국 분기** → 각 지역이 자기 플랫폼으로 좁혀짐(미국=틱톡·아마존·월마트 2×N, 중국=샤오훙슈). 질문 성격에 맞게 깊이가 다른 게 테크니컬.
- 페이지별 정체성 = **방마다 다른 웜워시 색/위치**(예: 협업=peach 우상단, 해외=lilac)로만. (배경 큰 숫자 같은 장식은 ⛔ — 반려됨.)
- 앵커 딥링크(#q01 등), 모바일=리스트→탭→결과(뒤로 가능), 데스크톱 무스크롤(한 화면).

## 4. ★이번에 비주얼로 풀 것 — 3섹션 관점
1. **히어로 (이번 1순위)** = **비주얼 임팩트(감성+기술)**. 인트로 화면과 메인 진입의 첫인상. **첨부 레퍼런스의 톤으로 여기 임팩트를 잡아줘.** 단 텍스트/정보는 안 늘림 — 임팩트는 타이포·여백·모션·웜워시·한 끗의 감각으로.
2. **Q&A 섹션** = 편안한 유저 경험 + 조용한 테크니컬 와우. 질문별 정보의 층위(위 해외 분기처럼)와 답의 위계를 세련되게. 박스 위계 차별화(후속질문=아웃라인 물음표 결 / CTA=Ink 솔리드 하나 / 레퍼런스=언더라인 텍스트링크 — 같은 알약 반복 금지).
3. **컨택 섹션** = "협업 제안하기"를 **하나의 경험**으로. 현재: 누르면 메일 앱에 깔끔한 최소 초안이 조용히 채워짐(화면엔 텍스트 안 늘림). 이 '눌렀을 때의 경험'을 세련되게(단 ⛔ 화면에 큰 초안 카드/주제 나열 같은 텍스트 덤프 금지 — 반려됨).

## 5. 레퍼런스 사용법
- 첨부 레퍼런스는 **히어로의 비주얼 임팩트 + 전체 무드/톤**을 위해 연구. **콘텐츠·텍스트를 늘리라는 게 아님.**
- 우리 톤 기준 = 배포 홈페이지(에디토리얼·웜워시·"Signal · Structure · Decision"). 레퍼런스가 화려해도 **SIRIAI 절제·웜워시·브랜드토큰**으로 번역해 흡수(레퍼런스를 그대로 베끼지 말고 결만).

## 6. 표시 게이트 (위반 시 실격)
단가/금액 숫자 비노출 · 미검증 수치 창작 금지 · 해외 '직접 운영' 표현 금지(**현지 파트너**) · 브랜드 실명은 **8division·무신사·이니스프리·코스알엑스만** · 상투어·벤더톤("문의 주세요")·이모지·과장("최고/1위/보장") 금지.

## 7. ⛔ 하지 말 것 (최근 반려 교훈)
- **배경 큰 숫자/워터마크 장식** 금지("구리다").
- **화면에 텍스트·카드 과밀** 금지(메일 초안을 화면에 통째로 까는 것 = "1차원적" 반려). 지능은 결과물에, 화면은 비운다.
- **사이드바 접힘** 다시 만들지 말 것. **시켜도 도금(gold-plate) 금지** — 가장 절제된 1차 해석으로.

## 8. 산출물 & 첫 요청 제안
구조·동작·JS 유지한 채 **최종 비주얼**(색 확정·타입·간격·모션·히어로 임팩트·박스 위계·질문별 최소 비주얼)을 **단일 HTML**로.
**첫 요청 예시:** *"첨부 레퍼런스 톤으로, 인트로→메인 전환의 **히어로 비주얼 임팩트**부터 잡아줘. 구조·인터랙션·브랜드토큰·게이트는 고정, 텍스트는 안 늘리는 선에서. 2~3개 방향 보여줘."*
