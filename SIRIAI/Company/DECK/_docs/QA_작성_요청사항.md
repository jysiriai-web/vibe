# SIRIAI Q&A 작성 요청사항 (스펙)

## 1. 구조 — 상위/하위 정확히 구분
- 대표질문(상위)과 후속질문(하위)을 명확히 표기.
  - 1. (대표질문)
    - 1-a (후속질문)
    - 1-b (후속질문)
- 정보의 층위: 대표질문 답은 짧게, 디테일은 후속질문으로 내린다.
- 각 답 끝에 "→ 이어서" 다음 질문 1~3개를 연결하고, 모든 경로는 결국 [협업 제안하기]로 수렴.
- 후속질문 라벨은 앞 맥락에 기대 짧고 센스 있게(예: 비용 답 아래 "예를 들면요?"). 같은 라벨은 플로우맵·"→ 이어서"·제목 세 곳에서 동일하게.

## 2. 대표질문 = 정확히 4개
- **비용 / 차별점 / 프로세스 / 인플루언서 섭외 외 진행**.
- 대표질문끼리는 (일부 제외하고) 내용이 겹치지 않아야 한다 — 그래야 다른 대표질문을 클릭할 이유가 생긴다.
- 서로 다른 후속질문이 '동일한 지점'으로 수렴하면 안 된다 (= 같은 내용 페이지를 2개 만드는 셈 = 꼬임).

## 3. 말투
- 차분한 존댓말(홈페이지 결). 단, 빳빳한 '~합니다' 일변도 금지.
- 기본형: 정보는 단문 + 마무리는 따뜻한 해요체(연결드려요 / 찾아드려요 / 제안드려요 / 좋아요), 사이사이 '~합니다'를 섞어 리듬을 만든다.
- 금지: 수다체(거든요·더라고요·잖아요), 느낌표, 이모지, 과장·미사여구.

## 4. 톤앤무드
- 단정·자신감. 저자세·변명조 금지. 핵심은 명료하게 긍정("됩니다").
- 프리미엄·절제·여유. 파트너 포지션(대행/벤더 프레임 금지 — 설계·발굴·핸들링·협상의 주체).
- 브랜드(고객사)를 띄우는 단어 선택. 양이 아니라 질로("더 좋은 감도", "거품 없는 가격").

## 5. 흐름·가독성
- ★끊김 금지: "○○입니다. □□입니다." 식으로 단문이 뚝뚝 끊겨 연속되는 글 금지. 자연스럽게 이어 읽히게.
- 쉬워야 한다. 읽는 사람이 편하게 읽히는 것이 최우선.
- 항목이 많은 곳(장점·단계·서비스 종류)은 불렛/번호, 나머지는 줄글로 분기.
- 명사형 단계, 역할 분리 명시(예: AI=정량 / SIRIAI=정성)처럼 한눈에 들어오는 구조.

## 6. 길이·압축
- 텍스트 최소화. 길게 늘이지 말 것. 한 문장이면 한 문장.
- 금지: 시키지 않은 부연·변명 단서절("다만 ~하지는 않습니다"), 반복·대구 수사, 군더더기 클로징, 전문용어 과시(ER 등).

## 7. 사실·게이트
- 숫자 노출 OK: 단가(릴스 10~25만), 리스트 1.5~2배수, 일정 일수.
- 실명은 8division·무신사·이니스프리·코스알엑스만.
- 사실 정확(지어내기 금지). 광고 표기 등 컴플라이언스 준수.

## 8. 작업 방식 (참고)
- 거칠게/메모로 적힌 부분은 맥락을 읽어 같은 문체로 '완성'한다. 괄호 placeholder("(1~2주)" 등) 방치 금지.
