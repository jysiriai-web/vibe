# 클로드 디자인 사용법 — 처음 가이드

> **두 파일 관계부터:**
> - **이 문서** = *어떻게* 쓰는지 (사용법)
> - **`클로드_프롬프트.md`** = *무엇을* 붙여넣는지 (재료)
> → 이 문서 보고 → `클로드_프롬프트.md` 복사 → 클로드에 붙여넣기 → deck 초안.

---

## 1. 클로드 디자인이 뭐예요?
**claude.ai**(웹/앱)에서 대화로 **HTML 웹페이지를 만들어주는 것**이에요. 결과물이 오른쪽에 **미리보기(artifact)**로 떠서, 바로 보면서 고칠 수 있어요. 디자인 툴을 못 다뤄도, **말로 시키면** 됩니다.

---

## 2. 단계 (그대로 따라하기)

1. **claude.ai 접속** → 로그인 → **새 대화** 열기
2. **`클로드_프롬프트.md` 열어서** `─── 프롬프트 시작 ~ 끝 ───` 사이를 **통째 복사**
3. 클로드 **입력창에 붙여넣기 → 전송**
4. 잠시 기다리면 **오른쪽에 HTML 미리보기(artifact)** 가 생겨요 → deck 1차 초안
5. 미리보기 보면서 **고칠 점을 말로** → 클로드가 수정 → **이 과정을 반복**

> 💡 한 번에 완벽하지 않은 게 정상이에요. 3~5번을 여러 번 돌리며 다듬는 거예요.

---

## 3. 수정하는 법 — "구체적으로" 말하기

| ❌ 막연하게 | ✅ 구체적으로 |
|---|---|
| "더 예쁘게" | "Hero 그라데이션을 더 진하게, 제목 폰트 더 크게" |
| "느낌 살려줘" | "각 섹션을 좌측 텍스트 / 우측 이미지 카드로 나눠줘" |
| "카피 좋게" | "2번 관점 섹션 카피를 더 짧고 강하게, 3가지 버전 보여줘" |
| "이미지 넣어" | "비주얼 자리에 회색 placeholder 박스 + 캡션만 넣어줘" |

**팁:** "○번 섹션을…"처럼 **위치를 콕 집어** 말하면 잘 고쳐줘요.

---

## 4. 미리 알아둘 것

- **이미지:** 클로드는 실제 사진을 만들지 못해요 → **회색 placeholder 박스**로 자리만 잡아요. 진짜 사진/그래픽은 나중에(Figma나 디자이너) 채워요.
- **길이:** deck이 길면 클로드 답이 중간에 끊길 수 있어요 → "이어서 해줘" 하거나, **섹션별로 나눠** 만들어도 돼요.
- **저장:** 마음에 드는 버전은 artifact 우측 메뉴에서 **복사/다운로드**. 또는 저한테 가져오시면 됩니다.

---

## 5. 결과를 저(여기)한테 가져오는 법

초안이 나오면 — 셋 중 아무거나:
1. **artifact 코드 복사** → 여기 채팅에 붙여넣기
2. **화면 캡처** → 여기에 올리기
3. 그냥 **"이렇게 나왔는데 어때?"** 라고 말 걸기

→ 그러면 제가 보고 *"여기 더 깊게, 저 카피 이렇게"* 같이 다듬고, 필요하면 **`클로드_프롬프트.md` 자체를 고쳐서** 다시 넣게 해드려요.

---

## 6. 막히면
- 결과가 영 아니면 → **그대로 가져오세요.** 프롬프트를 손봐서 다시 시도해요.
- 프롬프트를 바꾸고 싶으면 → 말씀만 하시면 제가 `클로드_프롬프트.md`를 수정해요.
- **완벽하게 한 번에 X, 같이 반복해서 O.** 편하게 던져주세요 🙂
