- **4 Practices 구조 동일** (Architecting / Visual Content / Software Engineering / Private Brand). ✅
- **디자인 원칙 일치** — 화이트·영어 베이스·미니멀·도시시계(monopo식). PRD의 톤 원칙과 정확히 맞음. ✅

- **PB도 당당히** ("proving insight directly through products"). ✅

### 2.2 ★핵심 프레이밍 — 사업소개서의 진짜 역할
> **팀장님 홈 = 추상적 비전 선언** ("Insight isn't found. It's designed")
> **우리 사업소개서 = 그 비전의 구체적 증거·실체**

방문자 여정:
```
[홈] "와, 관점 멋진데?" (추상·비전)
  └→ #deck / 링크 클릭
[사업소개서] "오, 진짜로 이렇게 하네?" (증거·프로세스·실적·실체)
  └→ Contact "같이 해보자"
```
→ **이게 사업소개서가 존재하는 이유.** 홈이 "무엇을 믿는가"라면, 소개서는 **"그걸 어떻게 증명하는가"**. (자세한 함의는 [`사업소개서_필요사항.md`](사업소개서_필요사항.md) §0)
