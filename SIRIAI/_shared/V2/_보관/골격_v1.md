# SIRIAI 사업소개서 — 골격 v1 (rebuild, 처음부터)

> 2차 재설계. 팀장 피드백(사업소개서답게 · 방문자 목적 · 한눈 목차 · 갑자기 아키텍팅 X · 02 케이스 · 자간/폰트/색) 반영.
> 방식: **항목마다 여러 안을 깔고 → 왜 그 안인지 근거와 함께 권장.** 준용 레퍼런스·내용 들어오면 빈칸 채워 확정.
> 작성: 2026-06-04

---

## 0. 가장 큰 교정 (팀장 피드백의 핵심)
1차 deck = **"갑자기 아키텍팅 후 쭉 내 얘기"** = 영업메일. 원인: 방문자의 *문제·맥락*에 공감하는 **도입**이 없고 바로 사업영역(자랑)으로 직행.
→ 교정: **① 방문자가 왜 들어왔는지 정의 → ② 그 문제에 공감하는 도입 → ③ 전체를 한눈에 보여주는 목차 → ④ 그 다음에야 영역별 깊이 + 증거.**

---

## 1. 방문자 목적 — "누가 왜 들어왔나" (제일 먼저 못 박을 것)

**안 비교:**
| 안 | 방문자 | 들어온 목적 | 리스크 |
|---|---|---|---|
| **A (협업 검토자)** ★ | 홈/미팅 거쳐 온, 마케팅·브랜딩 맡길지 보는 **브랜드 담당·대표** | "이 팀 믿을 만한가? 뭘 잘하나? 우리 문제 풀어주나?" | 가장 현실적 — 현 매출원과 직결 |
| B (투자/파트너) | VC·제휴사 | "성장성·기술(sa:ai)·확장" | 아직 deck 목적 아님 (그건 IR) |
| C (채용/일반) | 구직·일반 | "어떤 회사" | 너무 넓어 초점 흐림 |

→ **권장 A.** deck은 **"협업을 검토하는 브랜드"**를 위한 것. 그가 얻어야 할 4가지:
1. **뭐 하는 회사인지 30초 안에** (목차/개요)
2. **내 문제(안 알려짐)를 이 팀이 이해하나** (관점·공감)
3. **진짜 하나** (케이스·수치 = 증거)
4. **어떻게 시작하나** (전환·연락 명분)
→ 이 4개가 아래 목차·서사를 결정.

---

## 2. 한눈 목차 (IA) — 팀장 "목차가 없다 / 한눈에"

**안 비교:**
- **안 A — 순수 서사형:** 문제→관점→4영역→증거→팀→연락. 스토리 강하나 *전체 조망*은 약함(팀장 "목차" 미충족).
- **안 B — 카탈로그형:** 첫 화면이 목차 인덱스 → 클릭해 각 영역. 조망 강하나 *공감·서사*가 죽음(딱딱한 회사소개).
- **안 C — 하이브리드** ★: **짧은 도입(문제·관점) → '개요/목차' 섹션(전체 한눈) → 영역별 깊이 → 증거 → 연락.**

→ **권장 C.** 팀장의 두 지적("한눈 목차" + "갑자기 아키팅")을 **동시에** 푼다:
- 도입(1~2섹션)이 "내 얘기"로 직행하는 걸 막고(공감),
- 개요 섹션이 "전체를 한눈에"(목차) 보여준 뒤,
- 영역별로 깊이 들어감.

## 3. 섹션 구성 (권장안 C 상세)

> 각 섹션: **역할 / 핵심 한 줄 / 들어갈 내용 / 왜 여기**

| # | 섹션 | 역할 | 핵심 메시지 | 내용 |
|---|---|---|---|---|
| 0 | **Hero** | 첫인상·관점 | "안 알려지는 건 도달이 아니라 **관계**의 문제" | 메시지 A + 서브(知り合い) + CTA |
| 1 | **관점 (문제 공감)** | 영업메일 탈피·공감 | "좋은데 왜 안 알려질까 — 도달의 함정" | 방문자 문제 인식 → 시리아이 렌즈(관계). *내 얘기 아직 안 함* |
| 2 | **★개요 / 한눈 목차** | 전체 조망 | "우리는 이 네 가지를 합니다" | 4영역(아키텍팅·비주얼콘텐츠·sa:ai·PB)을 **한 화면에 카드/인덱스로** + 각 한 줄. 클릭→해당 섹션 |
| 3 | **영역별 깊이** | 증명·디테일 | (영역별) | 01 아키텍팅 / **02 비주얼콘텐츠(심장·케이스 내장)** / 03 sa:ai / 04 PB |
| 4 | **증거 (Trusted by)** | 신뢰 | "로고로 자랑 안 함 — 목록이 안목" | 브랜드 리스트(공개동의分) + 종합 수치 |
| 5 | **Studio · R&R** | 자격 | "브랜드 운영하다 분사한 팀" | 4역할 + 사명(知り合い) |
| 6 | **전환 (Contact)** | 행동 | "막힌 결정 하나를 가져와 주세요" | **입력 폼** + mailto + 회사정보 |

**3번(영역별) 내부 — 영역마다 다른 깊이:**
- **01 아키텍팅:** problem solver 집단 / 틀 없이 A to Z (틈결 = 이력 없던 걸 완수한 근간). *짧고 강하게.*
- **02 비주얼 콘텐츠 (deck 심장):** 국내/해외 + 프로세스 + **케이스 스터디**(§4) + 후불제·리스크0. *가장 풍부.*
- **03 sa:ai:** "모든 SNS 콘텐츠 아카이빙 솔루션" (브랜드+개인 라이브러리) + 3축. *제품답게.*
- **04 PB:** 2026·필름/디스플레이 · 실루엣·여백으로 신비. *가장 절제.*

## 4. 02 케이스 스터디 (팀장 "02에 케이스 필요")

**구조 안 비교:**
- **안 A — 4단 서사** ★: `문제 → 시리아이 설계 → 실행 → 결과(수치)`. 사업소개서 표준, 설득력 강.
- 안 B — Before/After: 2단 대비. 임팩트 있으나 과정(노하우) 안 보임.
- 안 C — 데이터 대시보드: 수치 중심. 신뢰 강하나 스토리 약.

→ **권장 A(4단)**, 케이스는 익명/업종 표기:
1. **ZB1(→ "글로벌 음악 레이블")** — 일본 틱톡 챌린지, 업로드율 100%·NCT 55건
2. **레이티드그린(→ "글로벌 스킨케어")** — Global Seeding 75개국 시딩
3. (옵션) 틈결×에스더버니(→ "라이프스타일 플래그십") — 나노100·VIP130·매거진 (대외비 수위)
> ⚠️ 실명/HYBE·마루 노출은 준용 공개동의 확인 후.

## 5. 전환 — Contact (전에 안 한 것 = 입력 폼)

**안 비교:**
- 안 A — mailto만: 가장 단순. 모바일·이탈 시 약함.
- 안 B — **입력 폼** ★: 이름·브랜드(회사)·연락처·"막힌 결정 한 줄". 제출 → (mailto 프리필 or 이메일 전송). 전환율↑·진입장벽↓.
- 안 C — 캘린더 예약(Cal.com): 미팅 직결. 단 부담↑(초기엔 무거움).

→ **권장 B(입력 폼) + mailto 병행.** 폼 필드:
- 브랜드/회사명 · 담당자 · 연락처(이메일) · **"지금 막혀 있는 결정/고민 한 줄"**(시리아이 톤) · (선택)예산대
- 동작: 제출 시 정리된 내용으로 mailto 자동 작성 → jysiriai@gmail.com (서버 없이 정적 배포 가능). 추후 폼 백엔드(Formspree 등) 연동 가능.
- 카피: "막혀 있는 결정 하나를 가져와 주세요. 그 구조는 우리가 짜겠습니다."

## 6. 디자인 방향 (팀장 "자간·폰트·색 맞춰야")

- **타이포 스케일(토큰):** Display(본명조)·H1·H2·Body(Pretendard)·Label(Fraunces/모노) — 단계·자간 고정값으로 통일.
- **컬러 토큰:** 크림(bg)·잉크(text)·파스텔 액센트(라벤더/피치/소프트블루) 역할 고정. "색은 절제, 콘텐츠가 색."
- **간격 스케일:** 섹션 패딩·요소 간격 8px 베이스 토큰.
- **한눈 목차 UI:** 2번 섹션 컴포넌트 (4영역 인덱스 카드 + sticky 미니 네비?).
- 레퍼런스 조합: 준용이 모을 **사업소개서 레퍼런스**로 "기존 기준 탈피" → 토큰·레이아웃 조정.
