[korea seeding — 02 비주얼 콘텐츠 상세 화면 구성안]

이 서비스(korea seeding)를 deck에서 클릭했을 때 펼쳐지는 '상세 화면'에 들어갈 내용입니다.
위에서 아래로 읽는 순서이고, 각 블록은 [제목 + 본문 + 이미지 자리(개수/종류/위치)]로 구성됩니다.
텍스트는 실제 들어갈 카피 초안이고, 이미지는 '몇 장, 어떤 컷이, 어디에' 들어가는지를 표시했습니다.
(아직 초안 — 확인하고 고칠 부분 말해주면 반영)

============================================================

01 — 인트로

제목: 맞는 사람을, 매번 새로 찾습니다
본문: 시리아이의 국내 시딩은 이미 등록된 인플루언서 풀을 돌려쓰지 않습니다. 캠페인마다 브랜드의 목적과 결에 가장 잘 맞는 사람을 그때그때 새로 선별해 연결합니다.

이미지: 1장
- 종류: 대표 비주얼 (국내 인플루언서 콘텐츠 모음컷 또는 매칭 무드 이미지)
- 위치: 제목/본문 바로 아래, 가로 풀폭 1장

============================================================

02 — 무엇이 다른가

제목: 풀에서 고르는 게 아니라, 결을 읽고 발굴합니다
본문: 같은 리스트를 반복 제안하지 않습니다. 브랜드와 충분히 소통한 뒤, 그 브랜드에 어울리는 결을 먼저 읽고 거기에 맞는 인플루언서를 새로 찾습니다. 그래서 매 캠페인의 결과물이 브랜드 고유의 톤을 유지합니다.

이미지: 0~1장 (선택)
- 종류: 개념 대비 이미지 ('등록 풀에서 픽 vs 조건 맞춤 발굴' 간단 다이어그램) — 생략 가능
- 위치: 본문 옆 또는 아래

============================================================

03 — 선별 기준

제목: 브랜드가 원하는 조건으로, 정밀하게
본문: 성별과 연령대, ER을 비롯한 인게이지먼트 지수, 감도와 무드, 주 타깃층까지 브랜드가 원하는 조건을 세밀하게 반영해 후보를 좁힙니다.
예시:
- 10~20대 여성 / 팔로워 3천 이상 / 비포&애프터 가능 / 피부 표현이 깨끗한
- 30~40대 워킹맘 / 팔로워 1만 이상 / 단가 40만 원대 / 머릿결이 좋은

이미지: 2~3장
- 종류: 실제 인플루언서 프로필·콘텐츠 예시 캡처 (조건이 다른 톤을 나란히 보여주는 컷)
- 위치: 본문 아래 2~3장 그리드 (또는 예시 한 줄에 인플루언서 컷 1:1 매칭)

============================================================

04 — 리스트 제공

제목: 1.5~2배수 리스트로, 충분한 선택지 안에서
본문: 추려진 후보는 최종 진행 수량의 약 1.5~2배수 리스트로 제공됩니다. 브랜드가 직접 하는 일은 리스트 컨펌과 제품 발송까지이며, 이후 콘텐츠 업로드 관리와 진행 점검은 시리아이가 전담합니다.

이미지: 1장
- 종류: 제안 리스트 / 인플루언서 카드 화면 예시 캡처
- 위치: 본문 옆 또는 아래 1장

============================================================

05 — 진행 프로세스

제목: 소통부터 정산까지, 한 흐름으로
본문(6단계 흐름): 브랜드 소통 → 조건 기반 선별 → 1.5~2배수 리스트 제공 → 컨펌·발송 → 업로드 전담 관리 → 정산·보고서

이미지: 1장
- 종류: 6단계 프로세스 다이어그램 (가로 흐름)
- 위치: 본문 아래 가로 풀폭 1장

============================================================

06 — 사례 (선택)

제목: 실제로 이렇게 돌렸습니다
본문: (익명 케이스 1건) 업종 / 목적 / 한 것 / 결과 — 공개 가능한 국내 케이스 확보되면 삽입

이미지: 2~4장
- 종류: 실제 진행 콘텐츠 캡처
- 위치: 케이스 카드 안

============================================================

[이미지 총량 정리]
- 필수: 인트로 1 + 선별 기준 2~3 + 리스트 1 + 프로세스 1 = 약 5~6장
- 선택: 무엇이 다른가 1, 사례 2~4
→ 권장 6~8장 (디테일하게 가면 10장 안팎)

[비고]
- korea seeding 폴더에 아직 캡처가 없음 → 위 이미지 자리에 들어갈 실제 컷은 수집 필요.
- global seeding 폴더의 캡처 톤을 참고하면 서비스 간 통일감 유지에 좋음.
- 프로세스/개념 다이어그램(02, 05)은 실사진이 아니라 디자인으로 제작하는 그림.
