## 1. 누구를 노리나 (500 → 타겟)

인플루언서 마케팅은 **소비자에게 자기 브랜드를 파는 곳**만 필요하다.

- **Tier A (1순위):** 소비자 완제품 뷰티 — 스킨케어·메이크업·헤어·바디·향수·이너뷰티.
- **Tier B (조건부):** 인디·신생, 더마/코스메슈티컬, K-뷰티 수출(국내 인플 의향 확인), 뷰티 디바이스/테크.
- **제외 (Non-ICP):** 순수 원료·소재, OEM/ODM 수탁제조, 부자재·패키징·기계·물류·인증·B2B 서비스.
- **안전 제외:** 여성위생·생리대·의약품 등 민감군 + 우리가 이미 접촉했거나 진행 중인 브랜드.

→ 산출물 = **타겟 리스트**(브랜드 · Tier · 카테고리 · 부스번호 · 연락처).

## 2. 어떻게 확보하나 (3단계)

### Phase 1 — 사전 워밍 (6/15 ~ 6/30)
타겟 리스트 완성 + 현장 미팅 예열.
- 디렉터리 수집·세그먼트 → 타겟 리스트
- 이메일·인스타 보강
- 사전 터치 = **가볍게**(관계형). "7/1 참관 예정, 부스서 인사" — 하드 피치 금지.
- 현장 준비물: 부스 우선순위 · **원페이저(덱 대체)** · 명함

### Phase 2 — 현장 대면 (7/1 ~ 7/3)
대면 접촉 · 명함 · 관심도 캡처.
- Tier A 우선 부스 동선(홀·부스번호 기준)
- 30초 피치 + 질문("지금 인플루언서 마케팅 어떻게 하세요?")
- 관심도(상/중/하)·후속약속 그 자리서 기록
- 못 만난 Tier A = 사후 콜드로 분류

### Phase 3 — 사후 전환 (7/4 ~)
팔로업 → 미팅 → 계약.
- 만난 곳: "반가웠다 + 모멘텀 증폭" → 제안
- 못 만난 곳: "현장서 뵙고 싶었다" 부드러운 콜드
- 관심 보인 곳 미팅 잡기, (덱 근접 시) 정식 제안서

## 3. 핵심 자산 — 메일 → 랜딩페이지 → 문의 (팀 회의 2026-06-15)

**메일은 열람·클릭까지만, 설명·전환은 랜딩이 한다.**

- **STEP 1 · 메일 (Q&A 티저):** 기존 SIRIAI 메일 톤(굵은 주장 + "더 알아볼까요?" 질문 링크, ex "확실하게 다릅니다 → 어떻게 다를까요?"). 직관·쉬움 → 열람·클릭 유도. 브랜드별 특별 혜택 한 줄(ex 이니스프리 30만원).
- **STEP 2 · 랜딩페이지 (Q&A/챗봇):** 클릭하면 브랜드 궁금증을 쉽게 풀어줌. ex「Q. 북미 진출하고 싶은데 아무 준비 없어도 되나요? A. 네, 시리아이는 … 원큐 프로세스를 제공합니다」「Q. 국내 인플루언서 진행 방식은?」.
- **STEP 3 · 전환:** 끝에 항상 **"SIRIAI에 협업 문의하기"** CTA.
- **범용 베이스:** 메일·DM·QR 한 벌로 재사용. INTERCHARM은 서론/마지막만 변형.
- **INTERCHARM 개인화:** 브랜드별 **QR** → 스캔 → "안녕하세요 OO 담당자님, SIRIAI입니다" → 개인화 랜딩 + 전용 혜택. 행사 한정 이벤트 느낌.

톤: 단정 금지 · "X처럼" 금지 · 담백 · 쉬운 말 · 한 브랜드씩 맞춤.
⚠️ **SIRIAI 수치·단가·혜택은 준용 승인분만**(미검증 수치·단가 임의 생성 금지 — 기존 표시규칙 승계).
