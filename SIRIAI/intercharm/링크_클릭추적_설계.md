# 메일 링크 클릭 추적 — 설계 (구현 대기)

> 목적: 프로모션이 끝난 뒤에도, **메일 안의 모든 링크**에 대해 "어느 브랜드가 무엇을 눌렀는지" 남긴다.
> 지금은 프로모션 CTA(`?code=`)만 추적된다. 사업소개서·홈페이지 클릭은 안 잡힌다.

## 지금 상태

| 링크 | 추적 | 비고 |
|---|---|---|
| 프로모션 CTA | ✅ | `promotion.vercel.app/?code=RAT2649` — 코드가 브랜드를 식별 |
| SIRIAI와 어떻게 협업? | ❌ | `siriai-business.vercel.app/` |
| 어떤 서비스가 있나요? | ❌ | `.../#service` |
| 비용은 얼마나 드나요? | ❌ | `.../#price` |
| 홈페이지 | ❌ | `siriai.co.kr` |

## 방식 — 경유(redirect) 링크

메일의 모든 링크를 **기록용 주소로 한 번 감싸고**, 즉시 원래 페이지로 넘긴다.

```
현재  <a href="https://siriai-business.vercel.app/#price">비용은 얼마나 드나요?</a>

변경  <a href="https://siriai.../go?c={{code}}&t=price">비용은 얼마나 드나요?</a>
                                   ↑브랜드   ↑무엇을 눌렀나
```

`/go` 가 하는 일은 두 줄이다.
1. `c`(브랜드 코드)와 `t`(링크 종류)를 기록
2. 원래 주소로 302 리다이렉트 — **사용자는 아무것도 못 느낀다** (체감 지연 없음)

## 링크 종류(t) 정의

| t | 도착지 | 의미 |
|---|---|---|
| `promo` | promotion.vercel.app/?code=… | 프로모션 리스트 |
| `deck` | siriai-business.vercel.app/ | 사업소개서 메인 |
| `service` | …/#service | 서비스 궁금 |
| `price` | …/#price | **비용 궁금 = 가장 강한 구매신호** |
| `home` | siriai.co.kr | 홈페이지 |

## 구현 (vercel 함수 1개)

```js
// api/go.js  — 의사코드
export default async function handler(req, res) {
  const { c = '', t = 'deck' } = req.query;
  const DEST = {
    promo:   `https://siriai-2026intercharmkorea-promotion.vercel.app/?code=${c}`,
    deck:    'https://siriai-business.vercel.app/',
    service: 'https://siriai-business.vercel.app/#service',
    price:   'https://siriai-business.vercel.app/#price',
    home:    'https://siriai.co.kr',
  };
  await log({ code: c, target: t, at: new Date(), ua: req.headers['user-agent'] });
  res.redirect(302, DEST[t] || DEST.deck);
}
```

저장소는 무엇이든 됨(Vercel KV / 구글시트 append / Supabase). **가장 싸고 단순한 건 구글시트 append** — 이미 서비스계정이 있어 바로 붙는다.

## 마스터시트 반영

집계 결과를 기존 열에 넣는다. **새 열을 늘리지 않는다.**

| 열 | 채우는 값 |
|---|---|
| `브랜드 클릭` | 한 번이라도 누르면 `O` |
| `프로모션 코드 열람 횟수` | 프로모션 링크 클릭 수 |
| `비고` | 무엇을 눌렀는지 (예: `price·deck`) ← 영업 우선순위 판단용 |

## 왜 Mailsuite 대신 이 방식인가

- Mailsuite 픽셀은 **메일 1통마다 서버가 새로 발급**한다. 고정 코드를 템플릿에 붙여넣으면 294통이 전부 같은 1통으로 집계돼 무의미하다.
- 이미지 차단이면 열람 추적 자체가 실패한다. **클릭은 차단되지 않는다.**
- PRD 원칙과도 일치: *"열람은 허수, 클릭이 유일 유효신호"*
- **`price`를 누른 브랜드 = 최우선 후속 대상.** "열었다"보다 훨씬 실행 가능한 정보다.

## 언제

프로모션(7~8월)이 끝나갈 무렵. 지금 발송분은 프로모션 코드로 충분히 추적된다.
작업량은 vercel 함수 1개 + 템플릿 링크 5개 교체 ≈ 1시간.
