## 실행 (지금 할 것)

1. 시트 열기 → 상단 **확장 프로그램 → Apps Script**
2. 편집기 안의 기존 코드 **전부 지우고** → `Master.gs` **전체 붙여넣기** → **저장**(Ctrl+S)
3. 상단 함수 드롭다운에서 **`updateMaster`** 선택 → **▶ 실행**
4. (최초 1회) 권한 승인: 계정 선택 → 고급 → 이동 → 허용
5. 완료 토스트 확인 — `코드 신규발급 N개 · 기존유지 M개 · 동일메일 정리 12건`

**몇 번을 돌려도 안전.** 열이 이미 있으면 다시 안 만들고, 이미 발급된 코드는 절대 안 건드림.

## 이 스크립트가 하는 일

| # | 내용 |
|---|---|
| ① | `추가 담당자` 오른쪽에 **`프로모션 코드`** 열 삽입 (요약 수식·조건부서식·드롭다운 범위는 시트가 자동으로 밀어줌) |
| ② | 코드 **없는 행에만** 코드 발급 — `ABC1234` (영문 3글자 + 숫자 4자리) |
| ③ | 공식이메일 == 담당자이메일인 **12건** 정리 → 한쪽만 남겨 중복발송 차단, 사유는 `발송 시 주의사항`에 기입 |
| ④ | 요약의 비어 있던 **`명함` 라벨** 채움 |

### 프로모션 코드 = 대시보드 접근 키
```
(주)배쓰프로젝트 → BAT1764      주식회사 랑벨 → LAN4077
(주)아트페이스   → ART7517      ㈜바이오에프디엔씨 → BIO8813
```
- **앞 3글자**: 브랜드 우선(영문 브랜드명 → 이메일 도메인 → 홈페이지 → 한글 초성=사업자명)
- **뒤 4자리**: 자동 생성. 516개 전수 **충돌 0 · 형식위반 0**
- **★한 번 나간 코드는 고정** — 브랜드명을 바꾸든 정렬을 바꾸든 스크립트를 다시 돌리든 그대로. 새로 추가한 행만 코드를 받음
- 캠페인 접두사 없음 → 같은 브랜드는 8월 시트에서도 같은 코드(대시보드 연속성)

### 공식메일 = 담당자메일 (12건)
같은 주소로 두 번 보내지 않도록 한쪽만 남김.
담당자명이 있으면 담당자 쪽만("노수란님 앞으로 1회만 발송"), 없으면 브랜드 공식 쪽만.
