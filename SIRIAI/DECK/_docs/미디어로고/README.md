# 미디어 로고 — "함께한 미디어" 신뢰 요소

셀럽/케이스 영역에서 **얼굴(초상권) 대신 매체 로고로 신뢰**를 주는 용도.
미디어 로고는 게이트 안전 — 실명·초상권 게이트와 무관, 노출 가능.

## 파일 (이 이름으로 저장해서 이 폴더에 넣기)

| 파일명 | 매체 | 비고 |
|---|---|---|
| `daily-fashion-news.png` | DAILY FASHION NEWS (데패뉴 / 데일리패션뉴스) | 틈결 현장 취재 파트너 · 블랙/화이트 |
| `eyesmag.png` | eyesmag (아이즈매거진) | 블랙/화이트 |
| `mmm-mag.png` | MMM mag (MMM매거진) | 릴리 인터뷰 게재 · 그린/블랙 |
| `cido.png` | CIDO | 화이트/블랙 |
| `hiphye.png` | HIPHYE | 화이트/블랙(레드 악센트) |

## 메모
- 로고마다 색·반전이 제각각(MMM 그린, HIPHYE 레드, 일부 흑백 반전) → 흑백/크림 톤 랜딩에 얹으려면 **단색(모노) 버전으로 통일**하는 게 깔끔. (지금은 일단 원본만 모음)
- 사용 맥락: "셀럽 콘텐츠가 이런 매체에 실렸다" 로고 스트립 → 셀럽 게이트 우회.
