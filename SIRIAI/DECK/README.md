# SIRIAI · DECK

SIRIAI 사업소개 산출물 폴더. 두 갈래입니다 — **① 챗봇형 인터랙티브 사업소개 덱(V3, React)** + **② 세일즈 메일용 Q&A 랜딩** (현재 팀장님 클로드 디자인에서 진행, 콘텐츠 정본은 `_docs/`).

## 여는 법 (덱)
- **`열기.bat` 더블클릭** → 로컬 서버가 켜지고 브라우저가 자동으로 열립니다.
- 끄기: 까만 창에서 **Ctrl+C** 또는 창 닫기.
- ⚠️ `index.html` 더블클릭은 빈 화면 — 반드시 **`열기.bat`(서버)** 로.

## 폴더 (보이는 것)
| 항목 | 뭔가요 |
|---|---|
| **`열기.bat`** | ▶ 덱 실행 |
| **`_docs/`** | **Q&A 정본 작업** — 아래 표 참고 |
| **`_팀장본/`** | 팀장님 상품소개서 원본(`SIRIAI 상품소개서.html`)·추출 템플릿 |
| **`_archive/`** | 안 쓰는 것 모음(옛 랜딩 시안·구버전 문서). 안 봐도 됨 |

### `_docs/` 안 — Q&A 정본 4파일이 기준
| 파일 | 영역 |
|---|---|
| `국내_QA_최종.txt` | 국내 인플루언서 |
| `해외_QA.txt` | 해외(북미·중국·다른나라·비용) |
| `셀럽_QA.txt` | 셀러브리티(섭외·매거진·계약) |
| `브랜딩_QA.txt` | 브랜딩(모델·촬영·디자인·콘텐츠) |
| `qa_미리보기.html` | 4영역 **열화판 미리보기**(브라우저로 열어 챗봇 흐름 확인) |
| `자료정리_해외연예인브랜딩.{md,html}` | 수집 자료 정리(리서치용) |
| `QA_작성_요청사항.md` | 카피 작성 스펙(제미나이 다듬기용) |
| `_raw/` · `구상/` | 원자료 · 구상 이미지 |
| ⛔ `QA_콘텐츠_편집용.txt` | 사용자 수기 전용 — **건드리지 말 것** |

> 앱 기계장치(`src` · `public` · `node_modules` · 빌드 설정)는 숨김 처리됨. 그대로 동작합니다.
> 빌드 산출물 `dist/`는 정리 시 삭제 — 필요하면 `npm run build`로 재생성.

## 작업 방식
- **디자인은 클로드 디자인**에서 진행. 이 폴더에선 **콘텐츠(정본 4파일) 관리·구조화**만.
- 정본 4파일이 기준이고, `_archive`/자료정리 등은 참고·리서치용.
