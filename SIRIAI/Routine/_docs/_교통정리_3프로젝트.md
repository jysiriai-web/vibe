## 0. 깔때기 (전체 그림)
```
[진입]            [전환 허브]         [깊은 설명]        [전환]
메일 / QR·현장  →   Q&A 랜딩       →   사업소개서 V3   →   문의 · 미팅
                   ★3프로젝트 공유      (랜딩이 링크)
```
- 열람은 허수, **클릭이 유일한 유효 신호** → 모든 진입의 목표 = "랜딩 클릭까지".
- 랜딩은 궁금증을 빠르게 풀고 **문의**로 보내는 얕은 사업소개. V3는 깊은 사업소개. **같은 내용, 깊이만 다름.**

## 1. 세 프로젝트 정의 · 경계

### A. 세일즈 자동화 (이 폴더 / 엔진)
- **역할:** 콜드메일 파이프라인 엔진 + **공유 자산 생산처**.
- **소유:** 브랜드 리스트(intake), 메일 템플릿, **랜딩 base**, 개인화 param, 추적·회신·후속.
- **진입:** 메일 (자동·상시).
- 사업소개서는 자동화 *안에* 넣는 게 아니라 **깔때기 끝(V3)에 링크/첨부**.

### B. 인터참 (별도 트랙 / 현장)
- **역할:** 7/1~3 COEX 참가사 대상 현장 영업. 같은 깔때기에 **QR·현장으로 진입**.
- **공유받음:** 세일즈 자동화의 **랜딩 base·메일 템플릿·브랜드 리스트**를 가져다 씀.
- **고유:** 현장/QR 진입, 이벤트(한정 혜택), 부스 동선, **발송은 전용 수작업**.
- **⚠️ 경계(기존 원칙 유지):** 자동화는 **리스트 만들기까지만**. 인터참 메시지/발송은 전용 수작업. 일반 자동발송에서 인터참 대상 **suppress**.

### C. V3 사업소개 (별도 프로젝트 / 깊은 설명)
- **역할:** SIRIAI를 깊게 설득하는 본체(챗봇형 인터랙티브 사업소개).
- **연결:** 랜딩의 "더 자세히 →"가 V3로 링크. 메일엔 V3 PDF 첨부도 가능.
- 별도 진행. 자동화·인터참은 V3를 **참조만** 함.
