# 📋 보고서 — 추적·후속 (4_track · 8_followup) 어떻게 할 것인가

> 요청: 추적 부분 어떤 방식으로 할 건지, 현실적 어려움, 왜 해야 하는지. 쉽게.
> 갱신: 2026-06-13 (번호 정리: 제안=6, 미팅·계약=7, 후속=8)

---

## 0. 결론 먼저 (3줄)
1. **4_track** = "내가 보낸 메일에 반응이 있나" 추적. **회신 감지는 확실·쉬움, 열람·클릭은 본질적으로 부정확** → 회신 위주.
2. **5 다음은 6(제안)이 맞다.** 회신 오면 5(답장)+6(대시보드) 합쳐서 회신. 옛 "6 영업 파이프라인"은 어색했어서 → **8_followup(후속·리마인더)**로 재정의, 옆에서 도는 감시역.
3. 둘 다 **발송(3)이 돌아 데이터가 쌓여야** 의미. 지금은 설계 확정 단계.

---

## 1. 회신 이후 흐름 (5 → 6)
회신 예: *"우리 이런 인플루언서 필요한데 알아봐줄 수 있나? 리스트 주면 검토할게요."*

- **5 reply** — 회신 분류(관심/거절/문의) + 답장 초안 (2 compose 톤 맞춰)
- **6 proposal** — 그 브랜드 맞춤 제안 대시보드 (홈페이지·인스타 이미 확보 → 수동 확인 → 대시보드, 제작이력 있어 쉬움)
- **합쳐서 회신** — [5 답장 + 6 대시보드]를 한 번에 발송 → **7 deal**(미팅·계약)

## 2. 회신이 안 올 때 (4 → 8)
- **4 track**이 "무응답"으로 판정 → **8 followup**: 발송 N일 뒤(1~2주) 점잖게 리마인드 1회 → 다시 4 track
콜드메일은 1번보다 **2~3번 후속이 성과의 대부분.** 무응답을 사람이 못 챙기니 시스템이.

## 3. 4_track — 메일 반응 추적

### 왜 해야 하나
200통 보내놓고 **누가 열었나·답장했나 모르면 깜깜이.** 다음 행동(후속/제안)을 정하려면 반응을 알아야. 특히 **회신 = "관심"의 가장 강한 신호.**

### 신호 3종 (정확도·난이도 완전 다름)
| 신호 | 정확도 | 방법 | 난이도 |
|---|---|---|---|
| **회신** | ★★★ 확실 | 보낸 스레드에 답장 달렸나 Gmail API로 확인 | 쉬움(OAuth 1회) |
| **클릭** | ★★ | 추적링크 / Mailsuite | 중간 |
| **열람** | ★ 부정확 | 픽셀 / Mailsuite | 본질적 한계 |

### 현실적 어려움 (솔직히)
- **열람률은 허수다.** 구글이 이미지를 미리 당겨와 안 열어도 "열람" 찍히거나, 차단하면 열어도 미감지. 애플 MPP도 자동 열람 처리. → 참고용.
- **회신 감지는 깔끔.** "내 스레드에 답장 왔나"는 100% 확실. 단 Gmail OAuth 1회(읽기전용) 필요.
- **회신↔브랜드 매칭:** 발송 때 스레드ID를 시트에 기록 → 정확히 연결(3_send가 기록).

### Mailsuite CSV 실측 (1000행 분석, 0613)
실제 export 까봤더니 결론이 명확:
- **열람 = 1000/1000 (100%)** → **완전 허수.** 구글 이미지 프록시가 전부 자동 열람 처리. → **버린다.**
- **클릭 = 67/1000 (6%)** → 진짜 신호(링크 실제 클릭). 포트폴리오 클릭 = **관심 지표로 활용.**
- **매칭 = 이메일로 깔끔** (6월 연락처 ↔ CSV 수신자. 207개 중 27개는 과거 발송이력도 있음).
- **운영 = 반자동:** Mailsuite 실시간 API 없음 → 발송 후 너가 CSV export → 내가 클릭 매칭해 시트 갱신.

### 확정 추천
- **회신 = Gmail API** (확실·자동, OAuth 1회) — 핵심.
- **클릭 = Mailsuite CSV** (반자동·보조 관심신호).
- **열람 = 폐기** (실측 100%, 무의미).
- 결과 → 시트 `클릭/회신/회신일자` 갱신, 회신 오면 `발송단계=회신`. (`열람` 열은 안 씀)

## 4. 8_followup — 후속·리마인더 (옛 6 재정의)
- 시트의 `발송일자·회신일자·발송단계` 매일 훑어: "발송 N일 무응답" / "리드 M일 정체" / "미팅·계약 임박" 리스트업.
- 리마인드 초안은 2_compose / 5_reply 톤 재활용. 사람 검토 후 발송.
- **과도한 후속 금지**(횟수 상한·최소 간격). 수신거부 즉시 제외.
- 순서 단계 아니라 **옆에서 매일 도는 감시역** → 5→6 메인 흐름엔 안 끼어듦.
