# 2_compose — 메일 만들기

시트의 한 행 → 슬롯을 채운 완성 메일. **발송은 안 한다**(그건 `3_send`).

## 폴더

```
2_compose/
├─ render_intercharm.py      ← 이것만 실행한다
├─ templates/intercharm/
│   ├─ 발송용_인터참_사후팔로업.html   ← ✏️ 고치는 건 이 둘뿐
│   ├─ 발송용_플레인텍스트.txt
│   └─ assets/                      메일에 쓰는 이미지
└─ previews/intercharm/       결과물(자동 생성·덮어쓰기). 손대지 않는다
    ├─ CODE_브랜드.html / .txt
    └─ _manifest.csv          누구에게 뭘 보낼지 목록 → 3_send 가 읽음
```

## 템플릿을 고쳤을 때

**그냥 고치고 저장하면 된다.** 실행할 때마다 템플릿을 새로 읽는다.
파일명을 바꿔도 된다 — 폴더 안의 html·txt 를 자동으로 찾는다.

**⚠️ 슬롯을 새로 추가했을 때만 알려줄 것.**
`{{hook}}` 같은 걸 넣으면 렌더가 `미치환 슬롯 남음: ['hook']` 하고 멈춘다.
조용히 이상한 메일이 나가는 게 아니라 **아예 안 만들어진다.** 이름만 알려주면 연결한다.

## 슬롯 4종

| 슬롯 | 값 | 출처 |
|---|---|---|
| `{{brand}}` | 랑벨 | 시트 `브랜드명` (법인격 자동 제거: 주식회사 랑벨 → 랑벨) |
| `{{name}}` | 노수란 | 시트 `담당자`. 비면 문장이 "브랜드 담당자님"으로 자동 정리 |
| `{{code}}` | LAN4077 | 시트 `프로모션 코드` (코드박스 + CTA 링크 `?code=`) |
| `{{month}}` | 7월 | **실행한 날짜로 자동** |

제목은 템플릿이 아니라 `render_intercharm.py` 의 `SUBJECT` 에 있다.

## 실행

```bash
# 공식 이메일 · 2026 인터참 참가사 전체
python render_intercharm.py --csv ../../intercharm/data/live_master_latest.csv \
       --official-only --intercharm2026

# 몇 개만 골라서
python render_intercharm.py --csv ... --pick LAN4077,BAT1764
```

| 옵션 | 뜻 |
|---|---|
| `--official-only` | 공식 이메일로만 (담당자 이름 미사용 → "브랜드 담당자님") |
| `--intercharm2026` | 2026 인터참 참가사만 |
| `--from-no / --to-no` | 시트 `#` 범위 |
| `--cat 스킨케어` | 구분 필터 |
| `--track 명함` | 접점 필터 |
| `--limit 10` | 앞에서 N건만 |

## 자동으로 걸러지는 것

- 공식 이메일 == 담당자 이메일 → 제외(담당자 배치에서 1회만 발송)
- 이메일 형식 이상(`.co.k` 같은 오타) → 제외, 사유 출력
- 프로모션 코드 없음 → 제외
