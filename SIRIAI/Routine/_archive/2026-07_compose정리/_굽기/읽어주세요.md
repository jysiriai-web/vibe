# 히어로 굽기

히어로를 **이미지로 구워서** 쓰는 이유 — 이메일 클라이언트에서 웹폰트가 안 먹으면
한글이 맑은 고딕으로 떨어진다. 렌더 시점에 브랜드 폰트를 박아버리면 그 문제가 사라진다.

## 파이프라인

```
히어로_디자인원본.html      ← 여기서 고친다 (문구·크기·행간·굵기)
        ↓  node 굽기.js      3배 렌더 → hero_baked_raw.png
        ↓  1200x640 축소·JPEG
   assets/hero_baked.jpg
        ↓  vercel 배포 (siriai-mail-assets)
발송용_인터참_사후팔로업.html
```

## 현재 확정 사양 (E안)

```
font-size:34px  line-height:39px (1.15)  font-weight:400  letter-spacing:-0.015em
font-family:'Noto Sans KR','Inter Tight',Helvetica,Arial,sans-serif
```

siriai.co.kr 히어로 실측값은 `w500 / 자간 -0.02em / 행간 0.95` 였으나,
94px 기준 수치라 33~38px에 그대로 쓰면 두 줄이 붙는다. 굵기만 한 단계 낮춘 E안 채택.

## 쓰는 법

```
cd _굽기
node 굽기.js              # 현재 사양으로 1장
node 타이포_5안생성.js     # 크기·행간 5안 비교용
```

굽고 나면 `hero_baked_raw.png`(1800x960)를 1200x640 JPEG로 줄여
`assets/hero_baked.jpg`로 덮고, 호스팅에 올려야 반영된다.

## 주의

- `node_modules`는 puppeteer-core. 커밋하지 말 것.
- 배경 그라디언트는 `assets/hero_bg.png`. 원본이 바뀌면 같이 갈아야 한다.
- 이미지가 차단되면 히어로는 alt 텍스트만 남는다. 폰트 깨짐을 막은 대가.
