# 2_compose — 개인화 메일 작성 (사이클 2단계) 🔨 진행 중

## 1. 목적·목표
`1_collector`가 정리·검증한 리스트에서 **`발송적합도=적합`(179) 행만** 읽어 개인화 메일을 작성한다.
- 마스터 템플릿(고정)에 **`{{brand}}` + `{{hook}}`만 갈아끼움** (도장에 잉크만 바꿔 찍기)
- `{{hook}}` = 카테고리-핏 1줄 (격식체, 가볍게). 카테고리는 1_collector가 저장한 것 재사용(딥리서치 금지).
- ★**`메일주의`(안전장치) 열 필독·준수** — 1_collector가 박은 경고(예: 라엘=생리대 언급 금지, 스킨케어만 소구). 훅·본문이 이를 어기면 사고. 메일주의 있는 행은 훅 생성 시 그 제약을 프롬프트에 명시.
- 완성본을 **`_발송큐` 시트**에 쓰고 `발송단계=초안` → **사람 검토 대기**. (본문은 `archive/previews/{brand}.html`, 큐엔 경로만.)
- **발송은 안 함** (그건 `3_send`). 작성은 되돌릴 수 있어서 마음껏·dry-run.

## 2. 구조
```
2_compose/
├── run.py             진입점 (--compose --dry-run) (예정)
├── templates/
│   └── cold_v1.html   ★마스터 템플릿 (사용자 Gmail에서 캡처, 포맷 보존)
├── hook.py            훅 생성 (카테고리+브랜드명 → 1줄) (예정)
└── README.md
```

## 3. 기술 스택
- Python + `../_shared/`(시트)
- Claude API(**Sonnet으로 시작** — 퀄/토큰 측정 후 Haiku↓ 또는 Opus↑ 조정) — 훅 1줄 생성
- 얕은 웹검색 1번(카테고리) / 또는 `1_collector`가 저장한 카테고리 재사용
- 발송 도메인·Gmail 인증 **불필요** (작성만 함)

## 4. 기타
- 마스터 템플릿: 제목 `[SIRIAI] {{brand}}에 맞는 인플루언서 제안드립니다`, 슬롯 `{{brand}}`×4 + `{{hook}}`×1. (포맷: 볼드·이탤릭·밑줄·노란형광·블루링크·로고 보존)
- 훅 방침: **딥 리서치 금지(토큰)**, 카테고리-핏 1줄, "추리다" 금지, 5종 오프닝 구조 로테이션(변주).
- 템플릿 바꾸려면: 사용자가 자기 Gmail에서 수정 → 자신에게 발송 → 읽어서 `cold_v1.html` 갱신.
- 다음 단계 = `3_send` (작성된 READY 메일을 발송).
