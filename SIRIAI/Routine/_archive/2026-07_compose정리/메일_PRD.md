## 0. 북극성 (불변)
- 메일의 **유일 목적 = 랜딩 클릭.** 열람=허수(구글 프록시·MPP), **클릭이 유일 유효신호.** 모든 요소는 클릭에 복무.
- 깔때기: **메일 → Q&A 랜딩(클릭) → 사업소개(깊은 설명) → 문의/미팅.** 메일은 "맛보기+떡밥", 화려한 경험·상세 설득은 랜딩·사업소개서에서.
- 템플릿 = **첫 비주얼을 결정짓는 핵심 파트.** 디자인/카피는 담당이 따로 있어도, 아래 §5·§8 기술·구조 제약은 반드시 충족.

## 1. 두 트랙 = 둘 다 콜드, 개인화 입력만 다름 (불변 구조)
- **기본 전제: 둘 다 콜드.** 법적 취급(§3)·톤은 동일. "명함=웜/동의완료"로 완화하지 않는다.
- **유일한 차이 = 개인화 입력 깊이:**
  - 크롤링(6월): 브랜드/회사 단위 → 인사 "OO 담당자님"
  - 인터참 명함: **담당자 이름**까지 확보 → 인사에 실명(예: "OOO 님")
- **운영 분리는 유지**(법적 완화 근거는 아님): 인터참 = 일반 자동발송큐에서 **suppress + 이번엔 수동 발송**(자동틀은 스캐폴딩만). 이미 가드: `run.py`·`_ingest_chunk` 대조탭 + 발송큐 격리.

## 2. 발송 안전 (불변 · 최우선)
- **SEND_UNLOCKED 하드락**: `secrets/SEND_UNLOCKED` 없으면 모든 발송 차단. 기본=잠김.
- **사람 승인 게이트**: 6월 `발송단계=승인`인 행만 발송.
- **suppress**: 이미 접촉·수신거부·인터참·미팅/계약 이력 = 발송 제외.
- **이중발송 방지(누적식)**: `발송일자`/`발송단계` 찍힌 (브랜드,이메일)은 재처리·재발송 안 함.
- 발송량 기본 = **0**. 명시적 해제 시에만.

## 3. 정보통신망법 (콜드메일 법적 요건 · 불변) ★실법 반영
> 근거: 정보통신망 이용촉진 및 정보보호 등에 관한 법률 **§50**(영리목적 광고성 정보 전송 제한)·**§50-2**(자동수집·자동생성 연락처 금지)·**§76**(과태료 최대 **3천만원**, 건별). 우리 콜드메일 = "영리목적 광고성 정보"에 해당 → 아래 그대로 적용.

### (A) 매 발송 반드시 (안 지키면 명백 위반)
- **제목 맨 앞 "(광고)" 표기**(한글).
- **전송자 명칭·연락처 본문 명시.**
- **무료 수신거부(수신동의 철회) 방법 명시** + 거부 시 **즉시 발송중단**(suppress 반영). 거부 비용 수신자 부담 금지.
- **야간 21:00~08:00 발송 금지**(별도 사전동의 없으면).
- **자동수집 주소(§50-2)**: 실제 트리거 = ⓐ'무단수집거부' 명시 홈피(주로 공공·기관)에서 자동수집 ⓑ그 주소 **판매·유통** ⓒ그 주소로 스팸. 우리 방식(**공식 published 이메일·AI+수기 검증·비판매·타겟·무작위 스팸 아님**)은 이와 결이 달라 실질 리스크 낮음. ★단 '수집거부 명시' 사이트는 회피 + 이 방식(타겟·검증·비판매) 유지가 곧 방어논리. 블라인드 하베스팅 금지.
- **발송자 신원·출처 은폐·기망 회신유도 금지.**

### (B) 구조적 리스크 = 사전 동의 (★대표 사업판단 영역)
- 원칙: 광고성 정보 전송엔 **수신자의 명시적 사전 동의(opt-in)** 필요.
- **예외(거래관계)**: 거래로 **직접** 수집한 연락처 + **6개월 이내** + **동종** 재화 광고 → 동의 불요. **우리는 거래이력 없음 → 예외 해당 안 됨.**
- ⚠️ **순수 콜드메일은 "사전 동의"를 구조적으로 못 맞춤 = 회색지대.** (A) 형식요건을 다 지켜도 사전동의 부재는 남는다.
- **현실 리스크 벡터 = 수신자 신고 1건**(인터넷 기록 수사 아님). → **(A) 형식요건 + 저물량·타겟팅·공식이메일·즉시 수신거부**면 신고 자체가 안 생겨 실질 리스크 소멸에 가까움.
- **→ 판단(2026-06-25 준용): 위 방식(타겟·검증·비판매·즉시거부) 유지 전제로 감수.** 이 전제가 곧 컴플라이언스이자 방어논리.
- ⚠️ **B2B라고 면제 아님**: 회사 대표이메일은 *개인정보보호법(PIPA)* 대상은 아니나, *정보통신망법 §50*은 "수신자"에게 적용되어 **광고 전송엔 그대로 적용.**

### (C) 트랙별
- **크롤링(6월)**: 순수 콜드 → (A) 전부 + (B) 리스크 감수.
- **인터참 명함**: 자발적으로 준 명함 = **예외 여지 있음**(명함 취지에 부합하는 범위). 단 안전하게 (A)는 동일 적용.

## 4. 도달성 필수 요소 (불변 기술 체크리스트) ★핵심 — 누락 금지
- [ ] **인증 SPF·DKIM·DMARC** — 어떤 발송경로든 필수(인프라 최종선택은 추후지만 인증 자체는 불변). 개인 Gmail 발송 = **저물량 수동만** 안전.
- [ ] **멀티파트 발송** — `text/plain` + `text/html` 동시. HTML 못 읽는 환경은 텍스트로 fallback(자동 안전망).
- [ ] **인라인 CSS만** — `<style>`·외부 CSS 금지(Gmail이 벗김).
- [ ] **테이블 레이아웃 + max-width 560** — Outlook 안전(flex/grid 금지).
- [ ] **이미지 최소 · 이미지 꺼져도 완결** — 색블록·테이블로 "리치". `<img>` 배너 지양(스팸·차단 리스크), 쓰면 `alt` 필수.
- [ ] **불릿프루프 버튼** — 테이블/VML 버튼(Outlook 대응).
- [ ] **프리헤더** — 숨김 div, ≤45자, "제목의 다음 문장".
- [ ] **다크모드 대비** — 색 명시(배경/텍스트 반전 대응).
- [ ] **링크 1~2개** — 과다 링크 = 스팸 리스크.
- [ ] **스팸어 회피** — 무료·100%·대박·클릭 남발 등.
- [ ] **워밍업 · 저볼륨** — 콜드 안전선 15~25통/일, 12→25 램프업.
- [ ] **리스트 위생** — 바운스 제거 · 이메일 유효성 검증 · suppress 반영.
- [ ] **발송 전 렌더 QA** — Gmail·Outlook·Apple·모바일·다크모드 실측 후 발송.

## 5. 템플릿 기술 제약 (Gmail 렌더 · 불변)
- **됨**: 색블록·배경색·테이블·불릿프루프 버튼·웹폰트(fallback 필수)·`<img>`(주의)·GIF.
- **안됨**: SVG · JavaScript · CSS 애니메이션 · `:hover` · `position` · flex/grid(불안정).
- → 화려한 인터랙션은 **랜딩**, 메일은 **정적 맛보기.**

## 6. 톤 · 표시 규칙 (불변 브랜드)
- **톤 = 하십시오체 단정.** 해요체·물렁어미 금지.
- **브랜드명 = 인사 1회만.** 본문 남발 금지.
- **표시규칙**: 단가 비노출 · 미검증 수치 배제 · 해외 직접운영 표현 게이트 · 실명 동의 게이트.
- **온브랜드 토큰**: Paper #F3EEE2 · Ink #211A33 · 웜워시 #F6C9A8 · 라벨 JetBrains Mono. **검정블록·이모지 금지.**

## 7. 측정 (불변)
- **회신 = Gmail API(확실). 클릭 = Mailsuite(보조). 열람 = 폐기(허수).**
- 상태머신: `발송단계` = 초안 → 승인 → 발송 → 회신 → 리드 → 미팅 → 계약.

## 8. 템플릿 슬롯 계약 (불변 인터페이스)
- 슬롯: `{{brand}}` `{{담당자}}`(명함=담당자명, 없으면 "담당자") `{{hook}}` `{{land}}` `{{home}}`
- 랜딩 앵커: `#different` `#work` `#how` `#global` (메일 클릭요소 → 랜딩 해당 Q&A로 수렴). ※랜딩 구조 바뀌면 동반 변경.
- 멀티파트라 각 슬롯은 **html·plain 양쪽** 채운다.

## 9. 템플릿 필수 구성요소 (불변 스켈레톤) — 어느 시안이든 무조건 포함
**A. 콘텐츠·구조**
1. 발신 정체 — `SIRIAI · 인플루언서 마케팅 매칭`
2. 개인화 인사 — `{{담당자}}님` + `{{brand}}`
3. 훅 — `{{hook}}`
4. **클릭 떡밥 = 매칭 미리보기 블록**(본론, 형태 자유·존재 필수)
5. **메인 CTA → `{{land}}`**(메일의 유일 목적)
6. 회사 소개 링크 → `{{home}}`

**B. 법 필수(§3 §50)** — 7. 발신자 정보(SIRIAI·담당자·연락처) · 8. 무료 수신거부 한 줄 · 9. 제목 맨 앞 `(광고)`

**C. 기술 필수** — 10. 숨김 프리헤더 (+ 멀티파트·인라인CSS·테이블·불릿프루프 = 코드 마감)

> ⚠️ 디자인 시안은 보통 4·5(떡밥·CTA)만 챙기고 **7·8·9(법)·10(프리헤더)를 빠뜨림** → 프로덕션 마감 때 반드시 주입.

## § 변경 가능 (여기 안 못박음 — 별도 관리)
- 구체 카피(제목·훅·카드 문구) · 디자인/비주얼(담당 별도)
- 개인화 tier 확정(**현재 T1 잠정** = 카테고리·채널 기반 훅 1줄, 미확정)
- HTML 리치 수준(콜드도 fancy vs 콜드는 텍스트 우세) — **추후 결정**
- 발송 인프라 최종(개인 Gmail vs 전용도메인+ESP) — **추후 결정, 인터참은 우선 수동**
- 볼륨 숫자 · 발송 시간대 세부
