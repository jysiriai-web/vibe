# 신규 브랜드 대시보드 — 인테이크 (이것만 주면 끝)

> 목적: **브랜드명 + 홈페이지 + 시트** 세 가지만 전달하면, 그 브랜드 맞춤 제안 대시보드가 나오게 한다.
> 매번 손으로 깨작거리지 않도록, 아래 "주는 것 / 자동 / 고정"을 고정 규칙으로 둔다.

---

## 1. 전달할 것 (딱 3가지)

| # | 항목 | 예시 | 비고 |
|---|---|---|---|
| ① | **브랜드명** | `PONPISH` (영문 워드마크 기준) | 표지·타이틀·문서명에 자동 반영 |
| ② | **홈페이지 URL** | `https://ponpish.co.kr` | 여기서 색·커버이미지·슬로건을 자동 추출 |
| ③ | **인플루언서 시트** | 구글시트 링크 또는 CSV | `brand-sheet-template.csv` 양식. 큐레이션 리스트 + 집계 자동 |

> 추가로 한 줄씩 주면 더 좋은 것(없으면 ②에서 자동): **태그라인(슬로건)**, **브랜드 핵심색(hex)**.

---

## 2. 시트 양식 (③) — 컬럼 고정

`brand-sheet-template.csv` 와 동일하게:

| 컬럼 | 필수 | 예시 | 설명 |
|---|---|---|---|
| `name` | ✅ | 다혜 | 표시명 |
| `handle` | ✅ | lens.dahye | 인스타 핸들 (@ 빼고) |
| `followers` | ✅ | 17100 | **숫자만** (콤마·"만" X) → 자동 17.1K 포맷 |
| `views` | ✅ | 2200 | 평균 조회수, 숫자만 |
| `er` | ✅ | 2.46 | 인게이지먼트율(%) 숫자만 |
| `cost` | ⬜ | 600000 | 예상 단가(원). 내부본(`?mode=internal`)에서만 노출 |

- 행 수 제한 없음(권장 12~20). 집계(합산 팔로워·평균 ER·예상 조회수)는 **자동 계산**.
- 구글시트로 주면 이 컬럼 순서로 정리만 부탁. (탭 1개)

## 3. 자동으로 처리되는 것 (안 물어봐도 됨)

- **브랜드 색(악센트)** — 홈페이지/OG 이미지에서 추출 (저채도로 보정, SIRIAI 페이퍼 베이스에 맞춤)
- **커버 이미지** — 홈페이지 OG/대표 배너 사용 (없으면 웜워시 플레이스홀더)
- **슬로건/톤** — 홈페이지 카피 반영 (없으면 무난한 기본)
- **시트 → 큐레이션 + 집계 KPI** 자동
- **PDF(전체/간단) · 모바일 · 영업/내부 모드** 표준 장착

## 내부 메모 (작업자용)

새 브랜드 = `_SIRIAI_TEMPLATE/index.html` 복사 → `Dashboard/<브랜드>/<브랜드>.html`.
config의 **`[브랜드 입력]`** 표시 블록만 채운다:
`meta.name · meta.docTitle · brandKit.colors.accent(+soft) · brandKit.coverImage · copy.tagline · copy.coverDesc · domestic.comparison.ours · domestic.influencers(시트)`.
`[SIRIAI 공통]` 표시 블록(whyUs · process · closing.contact)은 손대지 않는다.
