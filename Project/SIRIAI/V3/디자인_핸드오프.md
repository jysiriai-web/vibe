# 디자인 핸드오프 — 클로드 디자인용

> Phase 4 산출물. **구조/로직은 건드리지 말고 스타일만** 손볼 수 있는 상태로 정리.
> 비주얼 변경은 거의 전부 `src/styles/tokens.css`(토큰) + 각 컴포넌트의 `.css`에서 끝난다.
> `.jsx`(구조·로직)와 `content.js`(문구)는 디자인 작업 중 건드리지 않는 게 원칙.

---

## 0. 작업 원칙 (3줄)
1. **색·폰트·간격·라운드·그림자·모션** → `src/styles/tokens.css` 변수만 바꾸면 전역 반영.
2. 특정 컴포넌트의 **레이아웃/디테일** → 해당 `components/<Name>.css` 만.
3. **문구**는 `src/content.js`, **구조/동작**은 `.jsx`. 디자인 단계에선 손대지 않는다.

## 3. 이미지 처리
- 실사진이 없으면 브랜드 가이드대로 **회색 placeholder + 캡션**(`ImagePlaceholder`)으로 자리만. 진짜 비주얼은 Figma/디자이너 단계.
- 답변 다이어그램은 V2의 **온브랜드 SVG**를 그대로 사용(`public/assets/diagrams/*.svg`). 교체 시 같은 폴더에 덮어쓰면 됨.
- `global seeding/capture`의 실제 캠페인 캡처 32장은 사례 썸네일로 투입 가능(동의 확인 후).

## 4. 클디(claude.ai) 단일 HTML로 옮길 경우
이 프로젝트는 React+Vite(다파일)다. 만약 최종 양산을 claude.ai 단일 HTML artifact로 한다면:
- `content.js`(문구)·`tokens.css`(토큰)·각 컴포넌트 마크업을 그대로 재료로 전달하면 1:1 포팅이 쉽다(토큰 주도 설계라 색/폰트 규칙이 한 곳에).
- 단, "살아있는 질문 칩 캐러셀"의 마퀴/일시정지/`prefers-reduced-motion` 동작은 반드시 유지.

## 5. 모션 메모
- 브랜드 원칙은 "스크롤 fade-in만, 차분히". V3는 **질문 칩 캐러셀만 예외**로 부드러운 auto-rotate(핵심 인상). hover/focus 정지 + `prefers-reduced-motion` 시 정적 리스트로 폴백되게 이미 구현됨 — 이 동작 의도는 유지.
