# 📌 먼저 읽어주세요 — 이 폴더 보는 법

## 페이지 여는 법 (둘 중 하나)
1. **`열기.bat` 더블클릭** → 서버가 켜지고 브라우저가 자동으로 열립니다. ← 제일 쉬움
2. 또는 터미널에서:
   ```
   npm run dev
   ```
   그다음 브라우저에서 **http://localhost:5173** 접속.

- 끄기: 까만 창에서 **Ctrl+C** 또는 창 닫기.
- ⚠️ **`index.html`을 더블클릭하면 안 됩니다** — 빈 화면이에요. 이 파일은 앱의 "껍데기"라 위 방법(서버)으로만 보입니다.
