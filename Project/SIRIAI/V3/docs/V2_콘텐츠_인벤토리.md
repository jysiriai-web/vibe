## 2. 인플루언서 비즈니스 (#1, ready) — 핵심 메시지/숫자/프로세스

### 핵심 차별 메시지
- "플랫폼은 가입자 안에서 매칭합니다. 우리는 **인스타 전체를 DB**로 보고, 매니저가 직접 핸들링하며, 플랫폼 유지비와 에이전시 마크업을 걷어낸 비용으로 일합니다."

- 후불제 = 업로드된 건수만 청구 = **리스크 0**.

### 프로세스 (7단계, 검증)
계약 → 캠페인 생성·**직접 컨택** → 리스트 → 컨펌 → 제품 발송 → 업로드 관리 → KPI 보고·정산

### 기간
- 평균 **영업일 14일 내외**. 세부: 리스트 1주 → 선정 2~3일 → 배송 1주 → 업로드 1~2주(러프하게 약 1달). PRD: "3~4일 내 리스트 제공."
