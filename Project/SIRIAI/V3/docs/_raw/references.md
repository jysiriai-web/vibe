### 4. Benchmark doc takeaways (`서비스소개서_벤치마크.html`, 19 decks) — brief

**What good service-intro decks do (common spine + proof patterns):**
1. **Spine:** cover (1-line definition/slogan) → problem → solution/positioning → service/capability → **proof** → process → CTA. For SIRIAI, make the **proof block the center of gravity (40%+)** since the goal is "증명" not "소개".
2. **Open with a one-line definition + 1–2 signature numbers** immediately (레뷰 SUMMARY, 그루브웹).
3. **"기존 방식 vs 우리 방식" left/right contrast** is the #1 persuasion device — borrow as "도달 중심 vs 관계 중심(sa:ai)" (top borrow priority).
4. **Number the service into 3–4 pillar modules** (인플루넷 01·02·03, 브랜더진 4기둥).
5. **Give proprietary SW its own full-screen chapter** — real screenshots + operating-ratio numbers (위치커머스, 투명한마케터들 80%AI+20%검수) → sa:ai as a standalone chapter, not a footnote.
6. **Repeat cases in one standard card format** — `[브랜드·목표 / 실행 / before-after 결과]`, 5+ cases.
7. **Proof = quantitative + qualitative + post-reporting bundled into each case** (롱블랙: search spike + client quote + D+7 report).
8. **Show raw work/screens, not claims** — leverage HTML dashboard: case thumbnail → click → real content/report, with a **mandatory one-line result caption**.
9. **Logo wall split into two pillars** (media / clients) with status labels (진행중/완료).
10. **Every big number needs a caption** (definition / period / sample) — big-number spam is the anti-pattern.

**Avoid (반면교사):** unsourced big numbers + "No.1/최저가/무제한" copy (스타일씨·레뷰); text trapped inside images; label-less numbers / quote-less testimonials; KPIs that are only targets with no real execution; feature/logo lists with no "why us" narrative; ending on email/link only with no CTA (8division·PEEP·인플루넷).

**Competitive coordinates:** 레뷰 (scale leader, weak content depth + no AI), 인플루넷 (manpower brokering — adjacent, a SIRIAI partner), 인플루언서컴퍼니 (China direct-ops + list pricing), 브랜더진 (closest structural twin), 투명한마케터들 (sa:ai near-clone, but K-Korean niche). **SIRIAI differentiation:** ① "도달이 아니라 관계" to escape scale/price wars ② **sa:ai as an independent tech pillar** (competitors only graze AI in one line = the gap) ③ 8division lineage (Salomon · New Balance · CAMPERLAB global TIER-0) as relationship/quality proof.
