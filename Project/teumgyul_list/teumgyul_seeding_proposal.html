Why — 기획 배경

팝업은 끝났지만,
자산은 남아있다

5월 팝업으로 쌓은 인지도가 단발로 소진되지 않도록 구조를 전환합니다.

팝업으로 확보한 자산
나노 인플루언서 92명 + 메가 2명(릴리·김고은) 검증된 풀

데패뉴 매거진 파트너십 · 콘텐츠 레퍼런스 축적

성수 공간에 대한 초기 인지도
단발 캠페인의 한계
팝업 종료 = 콘텐츠 생산 종료

메가 인플루언서 모멘텀이 일회성으로 소진

검색 노출 / 해시태그 자산이 누적되지 않음
시딩으로의 전환
매월 안정적 콘텐츠 공급 →
인스타·유튜브 지속 노출

단골 인플루언서 풀 형성 →
광고티 없는 자연스러운 콘텐츠
"한 번 뜨고 사라지는 팝업"이 아닌  →  "꾸준히 회자되는 공간"으로.
이벤트 구조에서 상시 운영 구조로의 전환이 이번 기획의 핵심입니다.
02 / 07
Strategy — 운영 구조

듀얼 트랙으로
제품과 공간을 동시에

PB 악세사리 시딩과 공간 방문형을 병행해 온·오프라인 접점을 모두 확보합니다.

Track A
PB 악세사리 시딩
7~10명 · 제품 발송 후 자택 촬영
  • 에스더버니 반지·팔찌 등 기존 PB 악세사리
  • 일상/패션/주얼리 카테고리 나노~미들 인플루언서
  • 팝업 참여자 우선 재섭외 (관계 자산 활용)
  • 콘텐츠 포커스: 제품 매력 + 스타일링
  • 파트너십 코드: 온라인 할인 코드
Track B
공간 방문형 시딩
8~10명 · 틈결 플래그십 직접 방문
  • 상시 운영 공간 + 월별 이벤트 체험
  • 일상/공간/카페 카테고리 · 외국인 일부 포함
  • 콘텐츠 필수 3요소: 동선 + 공간 경험 + 이달의 이벤트
  • "가는 법 + 가야 할 이유"가 묶인 검색용 콘텐츠
  • 파트너십 코드: 매장 방문 시 굿즈 증정 코드
💡 두 트랙의 시너지 — PB 시딩 인플루언서가 다음 달 방문형으로 재등장하면, 팔로워 입장에서는 "그때 그 반지 한 친구가 매장에도 갔다"는 자연스러운 재방문 서사가 만들어집니다. 광고티가 사라지고 브랜드 신뢰도가 쌓이는 구조입니다.
03 / 07
System — 파트너십 코드

전원 코드 발행,
도달이 아닌 전환을 측정

단순 노출 수치에서 벗어나 실제 행동 데이터를 확보합니다. PB·방문형 트랙 전원 개인 코드 발행 의무화.

01
성과 추적
인플루언서별 실제 전환(구매·방문)을 측정합니다. 팔로워 수가 아닌 진짜 영향력을 데이터로 파악합니다.
02
팔로워 혜택
할인 또는 굿즈 증정으로 팔로워의 저장·공유율을 높입니다. 콘텐츠 수명이 길어지는 효과가 있습니다.
03
재계약 근거
코드별 성과 데이터를 축적해 다음 달 재섭외 인원 선별에 활용합니다. 감이 아닌 근거로 운영합니다.
트랙별 코드 차별화 (제안)
트랙 혜택 형태 적용 채널
Track A (PB) 온라인 할인 코드 자사몰 결제 시 입력
Track B (방문) 굿즈 증정 코드 매장 방문 시 제시
확정 필요 사항
  • 할인율 또는 혜택 종류 (10%·사은품·무료배송 등)
  • 코드 유효 기간 (업로드 후 30일 / 60일)
  • 발행·관리 주체 (클라이언트 vs SIRIAI)
  • 방문형 오프라인 코드 운영 방식 (POS 입력 vs 수기 확인)
04 / 07
Global — 외국인 인플루언서 전략

성수를 찾는 외국인이
틈결을 먼저 검색하게

일본·중국 관광객의 성수동 유입이 늘고 있습니다. 외국인 인플루언서가 추천한 공간으로 인바운드 동선에 안착하는 것이 목표입니다.

A안 · 안정형
한 7 : 외 3
국내 도달 우선 전략. 외국인 인플루언서 풀 확보 부담이 낮고 운영이 안정적입니다.

단, 외국인 시딩의 임팩트가 약해 인바운드 효과는 제한적입니다.
권장
C안 · 트랙 분리형
트랙별 분리
PB 트랙은 한국 100% (국내 구매 전환 집중)
방문형 트랙은 5:5 (인바운드 타겟)

각 트랙의 목적에 맞게 인플루언서를 구성하는 가장 논리적인 방안입니다.
B안 · 집중형
한 5 : 외 5
외국인 도달을 본격화하는 전략. 인바운드 효과 극대화가 가능합니다.

다만 외국인 인플루언서 풀 확보 부담이 크고 예산 초과 가능성 있습니다.
💡 권장안 (C안) 실행 방법 — 방문형 외국인 5명은 한국 거주 일본·중국인 인플루언서(실행사 모집)로 진행. 추가로 한국인 콘텐츠 일부에 일본어·중국어 자막/캡션 병기해 검색 도달 보완.
단, 외국인 인플루언서 풀 실제 규모는 실행사 컨택 후 최종 확정이 필요합니다.
