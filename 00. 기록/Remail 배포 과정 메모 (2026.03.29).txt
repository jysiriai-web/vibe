**Remail 배포 과정 메모 (2026.03.29)**

**개발 환경**
- Google Antigravity (무료) 사용
- Next.js + Tailwind CSS + Claude API (claude-sonnet-4-6)

**배포 순서**
1. Antigravity에 PRD 붙여넣기 → 코드 자동 생성
2. GitHub 빈 저장소 생성 (github.com → New repository → Private)
3. Vercel 연결 (vercel.com → Add New Project → GitHub 저장소 선택)
4. Vercel 환경변수 설정: `ANTHROPIC_API_KEY = sk-ant-...`
5. 배포 완료 → remailsiriai.vercel.app

**팀원 공유**
- 링크: remailsiriai.vercel.app
- 첫 접속 시 본인 이름 입력 → 각자 스타일 등록

**코드 수정 후 반영 방법**
```
cd mail-writer
git add .
git commit -m "수정내용"
git push origin main
```
→ Vercel 자동 배포됨

**주의사항**
- Antigravity가 커밋하면 Vercel이 막을 수 있음
- 그럴 땐 `git commit --allow-empty -m "trigger deploy"` → `git push origin main`
- `.env.local` 파일에 API 키 있어야 로컬 실행 가능
- 브라우저 캐시 지우면 스타일 날아감 → JSON 백업 필수
