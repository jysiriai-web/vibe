**API 비용 절감 방법 (Remail 기준)**

**적용한 최적화**
1. 스타일 샘플을 매번 원본 전체 전송 → **요약본(styleSummary) 1장만 전송**으로 변경
2. 모델 변경: claude-sonnet-4-6 → **claude-haiku-4-5** (약 80% 저렴)
3. 요약본 자동 갱신 제거 → **수동 업데이트 버튼**으로 변경 (불필요한 API 호출 차단)

**샘플 구조**
- 고정 샘플: 최대 7개 (직접 등록)
- 학습 샘플: 최대 3개 (완료본 자동 저장, 오래된 것부터 삭제)
- 요약본은 샘플 3개 이상 쌓였을 때 수동으로 업데이트

**결과**
- 최적화 전: 메일 1통당 약 3~4센트
- 최적화 후: 메일 1통당 약 0.5~1센트 (약 4~8배 저렴)
- 팀 4명 한 달 예상 비용: **$1~2**
